# OpenCADStudio - Release v2026.42 (2026-10-18)

> **Summary:** Major release introducing native dynamic block authoring and evaluation; new DGN, PDF, and 3D model import workflows; a redesigned docking and Graphic Attributes workspace; broad web/PWA improvements; and extensive drafting, layout, automation, plugin, rendering, and file-compatibility work.

---

### 🌟 Notable Release Notes

* **Dynamic Block Parameters:** Karim Jerbi implemented native Point, Linear, Polar, XY, Rotation, Alignment, Flip, and Visibility parameter authoring and editing, including parameter grips and base-point insertion in the Block Editor. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Dynamic Block Actions & Tables:** Added Move, Scale, Rotate, Flip, Stretch, Polar Stretch, and Array action authoring and evaluation, plus Lookup tables, Test Block evaluation, and Block Properties Tables. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Import Workflows:** Added `IMPORT`, `DGNIMPORT`, `PDFIMPORT`, and `PDFSHXTEXT` support, with DGN V7/V8, 3D Studio, SAT/ACIS, STEP, IGES, WMF, PDF geometry, and SHX text recognition. *(Contributed by [@ramox81](https://github.com/ramox81), [@HakanSeven12](https://github.com/HakanSeven12), and [@sclMAX](https://github.com/sclMAX))*
* **Workspace & Graphic Attributes:** Introduced vertical palette rails, auto-hide flyouts, floating and grouped panels, draggable tabs, and a persistent Graphic Attributes palette. The docking workspace and the Graphic Attributes palette were contributed by [@MarcelP102](https://github.com/MarcelP102).
* **Browser & PWA:** Added in-place browser saving, offline PWA operation, crash recovery, web plotting, worker-routed file operations, expanded format support, and bounded image decoding. *(Contributed by [@afonsop](https://github.com/afonsop))*
* **Drafting, Views & Layouts:** Added `-VIEW`, `DVIEW`, `MVSETUP`, `PUBLISH`, `REFEDIT`, `TXT2MTXT`, `ATTMAN`, layout viewport creation and copying, and updates to selection, snapping, measurement, and geometry editing. *(Contributed by [@ramox81](https://github.com/ramox81), [@HakanSeven12](https://github.com/HakanSeven12), [@gianlucafiore](https://github.com/gianlucafiore), and [@turbuczn](https://github.com/turbuczn))*
* **Automation & Plugin APIs:** Expanded MCP preflight, entity schemas, batch bindings, guides, and capture resources; added reference-only entities, plugin entity labels, and control notifications. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi), [@YsDirector](https://github.com/YsDirector), and [@schoeller](https://github.com/schoeller))*
* **3D Modeling & Exchange:** Added associative extrusion/revolution/loft sources, associative arrays, mesh section tools, and FBX export. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*

### 🚀 New Features

#### Blocks & Definitions
* **Block Definition & Write Block:** Added command-line and dialog workflows for `BLOCK`/`BMAKE` and `WBLOCK`, with previews, block attributes, and open-in-editor actions. *(Contributed by [@ramox81](https://github.com/ramox81) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Block Editor:** Added a dedicated authoring palette, contextual ribbon, definition Properties, save-as workflow, Test Block preview, and isolated session history with save checkpoints. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Native Parameters:** Added Point, Linear, Polar, XY, Rotation, Alignment, Flip, and Visibility parameter placement and editing, with selection and editing of native parameter grips. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Dynamic Actions:** Added Move, Scale, Rotate, Flip, Stretch, Polar Stretch, and Array actions, including independent reference grips, editable action selections, and reference re-evaluation after definition changes. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Visibility States:** Added visibility-state authoring and block visibility commands, plus a visibility dropdown for dynamic block references in Properties. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Lookup & Block Properties Tables:** Added Lookup authoring, row evaluation on block references, reverse input validation, polar angle input, and Block Properties Table authoring from the editor. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Block Attribute Manager:** Added `BATTMAN`/`ATTMAN` with staged changes and one undo step per Apply. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **Associative Arrays:** Added `ARRAYRECT` and `ARRAYPOLAR`, editing from native records, and source editing through `ARRAYEDIT`. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Block Attribute Synchronization:** Added `ATTSYNC` to rebuild block-reference attributes from their definitions. *(Contributed by [@ramox81](https://github.com/ramox81))*

#### References, Import & Export
* **Reference Editing:** Added `REFEDIT`, `-REFEDIT`, and `REFSET` with nested reference editing, a working-set dialog and toolbar, and write-back to external references. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **External References:** Added command-line options and file types for `ATTACH`, `EXTERNALREFERENCES` open/close commands, `ERSTATE`, and `ULAYERS`. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **DGN Import:** Added `DGNIMPORT` for V7/V8 drawings, cells and shared cells, 3D elements, text, curves, references, and filled shapes. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **Model Import:** Added `IMPORT` support for 3D Studio, SAT/ACIS, STEP, IGES, and WMF, with `ACISIN` and `WMFIN` commands. STEP colors and trimmed/bounded IGES surfaces are retained. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **PDF Import & SHX Text:** Added PDF import dialog and command-line workflows with viewport measure scale and curve recognition. `PDFSHXTEXT` recognizes SHX text geometry and converts it to MText. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **SVG Export:** Added `EXPORTSVG` for native vector SVG output. *(Contributed by [@hvfrancesco](https://github.com/hvfrancesco))*
* **3D Exchange:** Added `FBXEXPORT` for drawing meshes and web-build support for OBJ import and STEP/STL export. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@afonsop](https://github.com/afonsop))*
* **Text Conversion & Outlining:** Added `TXT2MTXT` to combine text into MText and `TXTEXP` to convert text into character outlines. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Paste Formats:** Added `PASTESPEC` to choose the format used for clipboard pasting. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*

#### 3D Modeling, Geometry & Drafting
* **Associative Surfaces:** Added associative extruded, revolved, and lofted surfaces with spline, ellipse, and region-boundary sources. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **Mesh Section Tools:** Added mesh `SLICE`, live section cuts with top/bottom volume grips, and `SECTIONCULL` to remove geometry outside a section. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Selection Filter (`FILTER`):** Added advanced entity and attribute filtering with normalized logical operators. *(Contributed by [@turbuczn](https://github.com/turbuczn))*
* **Measurement Tools:** Added radius and angle measurement tools with a dynamic overlay, Quick mode in `MEASUREGEOM`, and region loop support in `AREA`. *(Contributed by [@turbuczn](https://github.com/turbuczn), [@HakanSeven12](https://github.com/HakanSeven12), and [@ramox81](https://github.com/ramox81))*
* **No-Trim Chamfer & Fillet:** Added `TRIMMODE=0` support to preserve source geometry during `CHAMFER` and `FILLET`. *(Contributed by [@YsDirector](https://github.com/YsDirector))*
* **Object Snap Overrides & Tangency:** Added transparent object-snap overrides during active commands and line tangency support while constructing arcs. *(Contributed by [@yztink](https://github.com/yztink))*
* **Selection Gestures:** Added drag-to-move and Ctrl-drag-to-copy, Ctrl-click selection of a polyline segment, configurable OSNAP capture radius, and controls for selection highlight opacity and width. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@gianlucafiore](https://github.com/gianlucafiore))*
* **Advanced Geometry Editing:** Added hatch boundary vertex grip actions, improved `STRETCH` for arcs and splines, and added `COMPARE` overlays for differences between drawings. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Views & UCS:** Added command-line `-VIEW` presets, orthographic UCS and window options, `DVIEW` twist, and custom solid, gradient, and raster view backgrounds. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Layout & Plotting Commands:** Added `MVSETUP`, batch `PUBLISH`, first-open layout viewports, and layout copying from the tab menu. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **Plot Output:** Added drawing layers to PDF output and retained PDF plotting in web builds with quality presets and an in-page preview. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@afonsop](https://github.com/afonsop))*
* **Other Drafting Commands:** Added `HPASSOC`, PGP alias-file import and UCS-follow workflows, plus a setting to control colored grid axes. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@Pictus08](https://github.com/Pictus08))*
* **Drafting Variables & Input:** Added `SELECTIONCYCLING`, standard `TRIM`/`EXTEND` mode with `TRIMEXTENDMODE`, current-layer transfer with `LAYCUR`, and typed-angle locking for the next point. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Image & Underlay Adjustment:** Added `ADJUST`, `-IMAGEADJUST`, and PDF/DWF/DGN underlay adjustment, along with `XDWGFADECTL` profile persistence. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **Block Rendering Efficiency:** Packed block-wire definitions into shared buffers and cached repeated block copies as lightweight wires. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Key Tips & Selection Feedback:** Added Alt-driven key tips for ribbon tabs, controls, and menus, and clearer per-pick selection counts. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **UCS & Snapping:** Added dynamic UCS on planar solid faces, clickable UCS origin setting, configurable OSNAP aperture, and snap marker size control. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@gianlucafiore](https://github.com/gianlucafiore))*
* **Dimension & Font Settings:** Added standard arrowheads to dimension pickers, font/plot-style folder options, and improvements to dimension text and style handling. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Startup Scripts:** Added `/b` startup script support, matching `--script`. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*

#### UI, Workspace & Graphics
* **Docking Workspace:** Added palette groups, vertical icon rails, per-edge auto-hide, flyouts, floating windows, grouped and draggable tabs, adjustable slot heights, and float/dock controls. *(Contributed by [@MarcelP102](https://github.com/MarcelP102))*
* **Layer Manager Palette:** Integrated `LAYERS` into the docking workspace with persistent layout behavior. *(Contributed by [@MarcelP102](https://github.com/MarcelP102))*
* **Graphic Attributes Palette:** Added fill, line, transparency, and lineweight controls, open-boundary handling, varied-value indicators, layer creation, and persistent docking. *(Contributed by [@MarcelP102](https://github.com/MarcelP102))*
* **Color Selection:** Added color-book folders and browsing, RAL Classic and CSS Colors books, document-color search, RGB/CMYK/gradient controls, and an eyedropper. *(Contributed by [@MarcelP102](https://github.com/MarcelP102))*
* **Menus & Command Line:** Added a classic pull-down menu bar, ribbon toggle, adjustable command-line opacity, and execution of rebound Space from the command line. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@theluckystrike](https://github.com/theluckystrike))*
* **Start Page & Recent Files:** Added a From Template action and selectable recent-file list, icon, and large-preview layouts. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Touch & Navigation:** Added touch gestures, selectable mouse navigation style, and orbiting around the surface under the pointer. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **MATCHPROP Cursor:** Added a paintbrush cursor while `MATCHPROP` is active. *(Contributed by [@Ch4rlos](https://github.com/Ch4rlos))*

#### Web, Automation, Plugins & Platform
* **Web Save & Recovery:** Added in-place saving with the File System Access API, persistent autosave snapshots, session restore, `?file=` deep links, and return of saved drawings to embedding pages. *(Contributed by [@afonsop](https://github.com/afonsop) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Web Worker & Format Support:** Routed `WBLOCK`, `SAVEALL`, and `ARCHIVE` operations through workers; added web support for image paste, `INSERT`, `SCRIPT`, CTB, `LAYTRANS`, XREF, DATALINK and data extraction workflows, plotting, OBJ import, and STEP/STL export. *(Contributed by [@afonsop](https://github.com/afonsop))*
* **MCP Workflow Tools:** Added side-effect-free preflight, on-demand entity creation schemas, batch bindings and summaries, specialist guides, capture resource links, and canvas pointer event replay. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Automation API:** Added spline creation and validation, selection-change events, external-change actions, and API control improvements. *(Contributed by [@YsDirector](https://github.com/YsDirector))*
* **Plugin Host API:** Added name-addressed XRecord operations, reference-only entities, native plugin notifications, and API v10 plugin-defined entity labels in Properties and automation records. *(Contributed by [@schoeller](https://github.com/schoeller))*
* **Plugin Registry:** Added the Construction Layers & Guides plugin. *(Contributed by [@AAD002-Dwg](https://github.com/AAD002-Dwg))*
* **Image & Font Support:** Added bounded raster decoding, WebP/GIF and remote images, Georgian and Armenian web fonts, and font-folder lookup for TrueType fonts. *(Contributed by [@afonsop](https://github.com/afonsop) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **System Font & Theme:** Followed the system UI font and added system theme support. *(Contributed by [@ManuVarkey](https://github.com/manuvarkey) and [@afonsop](https://github.com/afonsop))*
* **Drawing Defaults:** New drawings now use standard visual styles, and color names can show their palette index. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*

### 🐛 Bug Fixes

#### Blocks, Attributes & References
* **Circular Block Prevention:** Prevented recursive block definitions and render cycles, with safe handling when a drawing contains a cycle. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Block Explosion & Attributes:** Corrected `INSERT`/`MINSERT` explosion for transformed `ATTDEF` records, instance attributes, rotated arrays, ByBlock properties, ACIS solids, and wire Regions. Enforced constant attribute flags in `ATTEDIT`. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi) and [@sclMAX](https://github.com/sclMAX))*
* **Block Data & Copies:** Unified base-point handling and block definition operations; prevented cross-document copies from sharing extension dictionaries; preserved copied XDATA application names and dynamic block behavior. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Dynamic Visibility & Grips:** Kept copied references' visibility states independent, restricted previews to the active state, and improved dynamic action grip refresh and display. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Reference Editing & Clipping:** Fixed xref definition write-back and backup handling, retained XCLIP filters when copying references, and improved underlay visibility during REFEDIT. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **Block Placement & Rendering:** Corrected `PASTEBLOCK` placement, block extents for inserted solids, block-local draw order, and wipeout/hatch render cache invalidation. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@ramox81](https://github.com/ramox81), and [@gianlucafiore](https://github.com/gianlucafiore))*

#### Geometry, Snapping & Selection
* **Selection Gestures:** Improved quick click-click selection boxes, kept intentional lasso drags responsive, and prevented incidental pointer movement from starting lasso selection. *(Contributed by [@gianlucafiore](https://github.com/gianlucafiore))*
* **Extension Tracking:** Corrected Extension/OTRACK intersection acquisition, click commitment, guide origins, ray projection, and marker sizing. *(Contributed by [@gianlucafiore](https://github.com/gianlucafiore))*
* **Geometry Commands:** Improved `STRETCH` previews for arcs and splines, preserved arc height, sped up large `TRIM`/`EXTEND` picks, honored preselected extend boundaries, and joined filleted lines/arcs and separate chains correctly. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Extrusion History:** Preserved fallback profile data in group 295 and applied taper only when requested. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **Arc & Distance Input:** Corrected arc-length entry and editing, line tangency and trim contact precision, and `DIST` angle calculations using `ANGBASE` and `ANGDIR`. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@yztink](https://github.com/yztink))*
* **Grip & Hatch Interaction:** Kept model grips on the drawing plane and improved hatch pick performance in large drawings, including off-layer boundaries. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Snap & Selection Input:** Kept typed snap overrides subordinate to command options, prioritized computed tangent snaps correctly, and reset selection counts for each command. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*

#### Views, Dimensions & Interface
* **Layouts & Plot Units:** Preserved layout sheet state before first open, fit the first viewport to the sheet without dropping saved viewports, reopened layouts in their saved viewport, and kept paper units independent of model `INSUNITS`. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@gianlucafiore](https://github.com/gianlucafiore))*
* **Zoom Extents:** Correctly framed drawings located at survey coordinates in Zoom Extents and Zoom All. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Dimensions & Text:** Kept dimension picture blocks in place during world-space edits, improved radius dimension text placement and grip behavior, applied text-style height/width/oblique settings, and resolved `TXT`/`MONOTXT` stroke aliases ahead of same-named TrueType fonts. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@ramox81](https://github.com/ramox81), and [@YsDirector](https://github.com/YsDirector))*
* **Dimension Styles & Annotation:** Kept radius text aligned with its grip, based new dimension styles on the selected style, preserved model-height defaults for TEXT/MTEXT, and corrected annotative scale behavior. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Dialogs & Command Line:** Staged plot-style and point-style edits until acceptance, blocked edits to xref-dependent dimension styles, preserved typed command argument casing, and improved command-line focus. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Start & System Integration:** Restored the Start screen New action, opened the template picker at the default template folder, added a Windows Settings fallback for default-app configuration, and restored the macOS DMG Applications shortcut. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@KevinGriffin-new](https://github.com/KevinGriffin-new))*

#### Rendering, Plotting & File I/O
* **DWG Audit & Compliance:** Used codec audit and repair for corrupted drawings and corrected OCS-saved files for strict-reader compatibility. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **DGN, STEP, IGES & WMF Readers:** Bounded DGN element reads, hardened STEP/IGES/WMF parsing against crafted files, and corrected nested DGN elements, cells, text, and 3D line strings. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **PDF Import & SHX Recognition:** Improved imported geometry precision, SHX font resolution, text grouping and glyph coverage, drawing order, and file/page feedback; corrected fractional SHX arc decoding. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **PDF & Plot Output:** Preserved wide-polyline end caps and joins, drawing layers, requested plot-style precedence, and accurate sheet placement for window plots. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Plot Lineweights & Patterns:** Preserved thin lineweight widths and correctly emitted PDF dash patterns with sub-point lengths. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Underlay & XREF Integrity:** Preserved host layer 0 and Defpoints flags in XREFs, corrected DWF origin handling, and kept layout viewport rendering caches available. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Raster Handling:** Enforced image decode memory limits, handled oversized GIF/TIFF inputs, and kept adjusted images linked to their source files. *(Contributed by [@afonsop](https://github.com/afonsop) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Transparency & Draw Order:** Fixed transparent hatch layering and transformed wipeout/hatch masks in block inserts. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@gianlucafiore](https://github.com/gianlucafiore))*
* **3D Redraw & Underlays:** Redrew moved meshes at their new positions and preserved underlay snap behavior and origin data. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **Save Reliability:** Retried atomic file replacement when files are briefly locked and avoided waiting indefinitely for thumbnail or screenshot rendering during save. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
