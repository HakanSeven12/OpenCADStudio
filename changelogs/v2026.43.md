# OpenCADStudio - Release v2026.43 (2026-10-25)

> **Summary:** Extended native dynamic block authoring and evaluation; introduced QuickCalc; expanded HATCH, MLINE, REGION, drafting, automation and plugin-grip workflows; substantially improved DGN, PDF, STEP, IGES, WMF and 3D Studio exchange; and fixed drawing, annotation, plotting, rendering and large-drawing performance issues.

---

### 🌟 Notable Release Notes

* **Dynamic Block Authoring and Evaluation:** Added native value sets, paired and XY move sets, complete parameter frames, grip roles and positioning, action base points and offsets, polygon Stretch frames, Polar Stretch endpoint bindings, multi-output Lookup tables, evaluated geometry previews, dependency status and construction geometry. Authoring graphs and constraints can be edited on references and retained through copy, insert and Save Block As. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Everyday Drafting and Geometry:** Added live crossing-box `EXTEND`, Shift-based `STRETCH` subtraction, one-click HATCH trimming that preserves curved edges and holes, MLINE trimming, geometric `OVERKILL` settings, all-match `FIND`, REGION edge snaps/dimensions, `PELLIPSE`, selection-scoped `FLATTEN`, richer `LIST` and layer isolation prompts. *(Contributed by [@gianlucafiore](https://github.com/gianlucafiore), [@HakanSeven12](https://github.com/HakanSeven12), [@sclMAX](https://github.com/sclMAX) and [@YsDirector](https://github.com/YsDirector))*
* **Drawing Exchange and Interoperability:** Expanded DGN V7/V8 support for dimensions, notes, meshes, levels, curves and cells; improved PDF text and curved fills with encrypted-file password entry; and improved STEP, IGES, WMF and 3D Studio geometry/material handling. Added valid AP214 STEP mesh export and periodic DWG spline DXF support. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Annotation and Drawing Data:** Improved dimension and MLeader rendering/editing, clipboard dependency remapping, field and attribute copying, and purge safety so common edits and cross-drawing transfers preserve their content and references. *(Contributed by [@ramox81](https://github.com/ramox81), [@cmlad26](https://github.com/cmlad26), [@insanedps](https://github.com/insanedps) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **QuickCalc:** Added a dockable Standard/Scientific calculator with a shared expression engine for `CAL`, point and distance functions, units, `$` variables, system-variable `getvar()`, history, memory and keypad tools. *(Contributed by [@MarcelP102](https://github.com/MarcelP102) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Large Drawing Performance:** Reduced work in snapping, constraint solving, hatch processing, STEP reads, block previews, property aggregation, scene queries and repeated solid rendering. Benchmarked gains include a 3.1× Properties rebuild for 2,000 entities, 5.3× STEP assembly lookup, 4.3× constraint drag preview, and 27× bulk constraint refresh. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi), [@gianlucafiore](https://github.com/gianlucafiore), [@HakanSeven12](https://github.com/HakanSeven12), [@ramox81](https://github.com/ramox81) and [@MarcelP102](https://github.com/MarcelP102))*
* **Automation and Data Workflows:** Added headless `--batch`/`--each` drawing scripts, more dash-form commands, open-document automation without tab activation, OLE insertion/properties, hyperlink editing, data-link actions, richer extraction fields and semantic block/attribute data in MCP `ocs_read`. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@ramox81](https://github.com/ramox81) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Workspace and Navigation:** Added display-locked viewport pan/zoom, pointer-centered orbit, revised Zoom Extents framing, responsive floating palettes and a faster block gallery with cached, visible-row previews. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@MarcelP102](https://github.com/MarcelP102))*
* **Plugin Grips and Host API:** Added API v11–v13 built-in/custom grip reads and drags, live geometry, deterministic notifications, constraint and record APIs, and quiet commands. Non-blocking delivery, settle recovery and improved reentrant host access keep plugin grips responsive. *(Contributed by [@schoeller](https://github.com/schoeller))*

### 🚀 New Features

#### Blocks & Definitions

* **Parameter Value Sets and Frames:** Added min/max bounds, increments and allowed values for Linear, Polar, XY and Rotation parameters; paired Move and XY Move sets; complete native parameter frames; and parameter-specific Base, End and XY grips with relocatable display positions. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Stretch and Polar Stretch Authoring:** Added Linear Stretch Pair, XY Stretch Box Set and Polar Stretch Pair authoring, polygon Stretch frames, native Stretch targets for arcs, circles, ellipses, points and text, and Base/End bindings. Polar Stretch can separately select rotation geometry and retain rotate-only target size. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Actions and Grip Controls:** Added independent Rotate/Scale base points and native base offsets, Move/Stretch distance and angle overrides, action bars, `BGRIPSET`, grip repositioning, `BCYCLEORDER`, and authoring graphics/settings controls. Added `BASSOCIATE` to repair orphaned action bindings and feedback for dependency markers and grip roles. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Lookup, Properties and Evaluation:** Lookup tables now evaluate formulas and ranges, support multiple outputs, retain shared parameter links and allow row selection on references. Added native Flip labels, parameter names/descriptions, Visibility descriptions and reference properties. Drawing and Test Block previews show evaluated parameter geometry without mutating the resident drawing. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Construction Geometry and Status:** Added `BCONSTRUCTION` Convert/Revert and Show/Hide, persisted construction membership, and per-entity constraint status with editor shading. Added `RESETBLOCK`, `BTABLE`, and `PARAMETERSCLOSE`; added `BLOCKEDITLOCK` and read-only editor session variables. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Block Properties Tables and Save As:** Added native table grips with must-match behavior and reference-side row choice. Save Block As copies structured parameters, grips, actions, Lookup tables, visibility records and retained associative constraint graphs onto independent handles. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Block Gallery:** Added a gallery for drawing blocks with cached thumbnails, indexed names and previews generated for visible rows; library thumbnails load in the background. *(Contributed by [@MarcelP102](https://github.com/MarcelP102))*

#### Drafting, Annotation & Calculation

* **Live `EXTEND` and `STRETCH`:** Added spatially filtered live box/lasso previews, crossing-box extension of multiple lines to a shared boundary, and Shift-window or Shift-click subtraction of selected grips/vertices during `STRETCH`. Previews retain fixed original geometry for snapping and handle blocks, full precision and commit/cancel behavior. *(Contributed by [@gianlucafiore](https://github.com/gianlucafiore))*
* **HATCH Editing:** Added `HATCHEDIT` picking on fills, double-click and context-menu editing, fill-only entity selection, and trimming of polygonal and circular regions by finite line/circle boundaries. Repeated cuts preserve analytic curved edges, circular holes and islands; clipped associative hatches detach safely with a notice. *(Contributed by [@gianlucafiore](https://github.com/gianlucafiore), [@YsDirector](https://github.com/YsDirector) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Geometry Commands:** Added geometry-based `OVERKILL` with a settings dialog and `-OVERKILL`, all-match `FIND` with zoom-to-result, MLINE trimming between cutting edges, pattern-HATCH `EXPLODE`, and collinear line/same-circle arc `JOIN` across gaps. `FILLET` now ends after one corner unless Multiple is selected. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Regions, Snapping and Dimensions:** Added REGION boundary object snaps and mouse-pick acquisition, circular REGION edge measurements and associative dimensions, radius/diameter picks through blocks and viewports, and persisted snap aperture through Options and `APERTURE`. The Shift+right-click snap menu accepts letter keys and Perpendicular snaps rank with other nearest point snaps. *(Contributed by [@sclMAX](https://github.com/sclMAX) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Dimensions and Text:** Added per-object annotative state, multi-dimension property rows, angular measurements stored/read as radians, `DIMJUST` text beside extension lines, and `DATAEXTRACTION` position and rotation columns. Dimension context fit overrides are applied per scale. *(Contributed by [@ramox81](https://github.com/ramox81), [@cmlad26](https://github.com/cmlad26) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Drafting Input and Layers:** Added `PELLIPSE` to create bulged-polyline ellipses, stored with the drawing; Shift temporarily suspends Ortho and typed `<angle` applies only to the next point. `LAYISO` prompts for objects and `LAYUNISO` restores only layers it isolated; layer states can freeze layers in one viewport. `FLATTEN` and `LIST` prompt for objects, and `LIST` includes polyline vertices. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **QuickCalc and `CAL`:** Added a shared lexer/parser/evaluator supporting point literals and functions, assignments, `ans`, unit suffixes, angle modes, trigonometry, scientific functions and system-variable `getvar()`. Added dockable Standard and Scientific keypads, memory/history, unit conversion and persistent global `$` constants/functions. *(Contributed by [@MarcelP102](https://github.com/MarcelP102); review fixes by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Hyperlinks, OLE and Data:** Added Insert/Edit Hyperlink, `-HYPERLINK`, `HYPERLINKOPTIONS`, `HYPERLINKBASE` and Ctrl+K; added `INSERTOBJ`, OLE variables and an OLE Properties panel; added Insert-tab Data and Linking & Extraction panels with Data Link download/upload actions. `DATAEXTRACTION` includes insert/text rotation and Position X/Y/Z. *(Contributed by [@ramox81](https://github.com/ramox81))*

#### References, Import & Export

* **DGN Import:** Expanded V7/V8 support for named levels, cells, shared/unshared cell placement, 3D meshes, curves, filled shapes, dimensions and notes. Imported dimensions use file dimension styles/settings; V7 UOR fractions, sub-units, clockwise arcs, text code pages/fonts and dimension layout are handled. Empty imports now report that nothing was imported. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **PDF Import and Passwords:** Added a Password Protected PDF dialog for open/permission passwords and encrypted PDF underlays. Import reads optional-content layers, text runs, fill/stroke paths, linework and curved regions; supports clipping and text-height/font mapping; and reports when a page requires a password. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **STEP and IGES Exchange:** STEP import handles mapped items, missing units/products, operator scale and unnamed representations; STEP export writes faceted B-rep meshes in valid AP214 product structure. IGES import supports surface types 114/118/120/122/128/140/141, offsets, revolutions, whole spheres/tori, levels and free curves. *(Contributed by [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **3D Studio and WMF Import:** 3D Studio import supports legacy render records, object colors, material finish/transparency/shading/diffuse maps, multiple-material choice and missing-map reports. WMF import improves text alignment/ascent, spaces, and arc sampling/rounding. *(Contributed by [@ramox81](https://github.com/ramox81))*
* **Spline and Linetype Exchange:** DWG periodic splines now render; DXF writes full NURBS control points and knots for periodic and fit-method splines. Complex `.lin` files can load shape files beside the linetype or from the fonts folder, with absolute, rotated and upright (`A=`, `R=`, `U=`) element modes. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Raster and Archive Workflows:** `IMAGE` can place georeferenced GeoTIFF/world-file images at their stored world position, size and rotation, while retaining manual placement. `ARCHIVE`/`ETRANSMIT` resolve and include referenced drawings, images and underlays and list references that could not be found. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*

#### Automation, Plugins & Platform

* **Headless Drawing Scripts:** Added `--batch` and `--each`, sequential script rows, command-line `OPEN`/`SAVEAS`/`CLOSE`, save prompts for `EXIT`/`QUIT`, and dash-form `-LAYER`, `-PURGE`, `-STYLE`, `-RENAME`, `-DIMSTYLE`, `-LAYOUT` and `-PLOT`. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Automation Server:** Open drawings with missing xrefs and report each reference in `state.xrefs`; adopt drawing header system variables on open; enforce `--read-only` for headless save requests; and cancel commands even when dialogs or nested prompts are active. Automation can read/edit an open inactive document without switching the visible tab. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **MCP Block Extraction:** Added semantic block extraction to `ocs_read`, returning placed blocks with resolved dynamic names, attributes from ATTRIB/ATTDEF and visible schedule text, evaluated parameters, visibility and Lookup values, and spatial/glob/JSON-Pointer filtering. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Plugin Grip API v11:** Added per-entity built-in grip reads/drags, custom grip declaration and custom-grip begin/move/settle/cancel callbacks, with viewport and MCP paths sharing one pipeline. *(Contributed by [@schoeller](https://github.com/schoeller))*
* **Plugin Grip API v12:** Added live-geometry previews, per-entity batch reads, non-blocking delivery and a settle watchdog. Nested commands are rejected during delivery to prevent UI-loop deadlocks; canceled previews restore source entities byte-for-byte. *(Contributed by [@schoeller](https://github.com/schoeller))*
* **Plugin API v13:** Added deterministic notifications, changed-region payloads, constraint creation, batched records and `RunQuiet`. Plugin grip settle writes and constraints join one plugin undo step; the manager supports first-write re-entry and recovers from repeated delivery timeouts. *(Contributed by [@schoeller](https://github.com/schoeller))*
* **Viewport, Palettes and Platform:** Added display-locked viewport sheet pan/zoom and a status-bar lock switch, pointer-centered orbit, perspective field of view, and revised Zoom Extents framing. Floating palettes can move/resize from edges while preserving the drawing view; Mac trackpad pan/zoom and Linux/Windows DWG/DXF icons are improved. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@MarcelP102](https://github.com/MarcelP102) and [@Jeshuuu](https://github.com/Jeshuuu))*
* **Graphics and Defaults:** Added camera glyph control with `CAMERADISPLAY`, saved `EXTMIN`/`EXTMAX`, eight solid isolines in new drawings, and solid isoline spacing from the drawing setting. Added Vietnamese (`vi-VN`) localization. *(Contributed by [@ramox81](https://github.com/ramox81) and [@vandang890615](https://github.com/vandang890615))*

### 🐛 Bug Fixes

#### Blocks, Attributes & Drawing Data

* **Cross-Drawing Clipboard References:** Copy/paste now remaps TABLE contents and cell blocks, raster image definitions, complex linetype shapes/text, MLeader styles and their text/linetype/block dependencies, and dimension-style text styles/linetypes/arrow blocks. Missing dependencies are cleared instead of retaining handles into the source drawing. *(Contributed by [@insanedps](https://github.com/insanedps))*
* **Copy Handles and Anonymous Records:** Renewed handles for INSERT sequence ends, polyface vertices/faces and polygon-mesh vertices. Pasted `*` blocks and copied/mirrored/pasted `*D` dimension blocks are marked anonymous, avoiding invalid DWG records and AUDIT errors. *(Contributed by [@insanedps](https://github.com/insanedps))*
* **Copied Fields, Attributes, Layouts and Viewports:** Cloned FIELD trees and attribute extension dictionaries so copied fields no longer share source data; copied viewport clipping boundaries follow the new viewport; copied layouts receive cloned extension dictionaries. *(Contributed by [@insanedps](https://github.com/insanedps))*
* **Purge References:** PURGE retains text styles referenced by MLeader/table styles, symbols used only by inserted attributes, dimension-style dependencies, current header layer/style/linetype and xref-dependent layers/linetypes/styles. *(Contributed by [@insanedps](https://github.com/insanedps) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Draw Order and XDATA:** New-drawing draw-depth labels now have resolvable spacing and rebuild the persistent wire arena after depth-generation changes, fixing masks that failed to cover earlier entities. MOVE/ROTATE/SCALE/MIRROR now transform XDATA point/vector/distance groups with the entity and remove stale raw records. *(Contributed by [@Jesus](https://github.com/Jeshuuu) and [@insanedps](https://github.com/insanedps))*
* **Dynamic Block Persistence:** Preserved dynamic graphs through INSERT/copy, native parameter frames and grip dependencies through edits, and constraint graphs through Save As. Fixed table-grip graph dependencies/column metadata, basepoint and parameter preview edits, orphaned grips, action bindings, angle wrap, rotation after base moves and stale input references. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Dynamic Block Safety:** Bounded Array evaluation to 100,000 generated entities before copying; updates remain atomic on refusal. Zero-grip parameters continue evaluating, invalid/unassociated grips are rejected, and grip counts, roles, positions and bindings remain consistent across references and DWG/DXF round trips. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi))*
* **Block Rendering and Preview:** Preserved tapered polyline widths inside INSERTs, retained legacy base-point previews and cleared editor selection on blank picks. Fixed incorrect previews after block saves and reduced unnecessary palette rebuilds. *(Contributed by [@cmlad26](https://github.com/cmlad26), [@KarimJerbi](https://github.com/KarimJerbi) and [@MarcelP102](https://github.com/MarcelP102))*

#### Geometry, Snapping & Selection

* **HATCH Boundary and Trim Accuracy:** Moving an associative hatch with its boundary now preserves each region. Internal picks use the raw cursor point, HPGAPTOL bridges small gaps without welding away tessellation chords, and boundary picks build only nearby face arrangements. Imported polyline cutters work; circular/curved holes and boundaries survive repeated cuts, while unsupported outer curves are refused rather than flattened. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@gianlucafiore](https://github.com/gianlucafiore) and [@YsDirector](https://github.com/YsDirector))*
* **HATCH Display and Persistence:** Erasing a boundary keeps the hatch’s shape and makes it independent; hatch fills use even-odd behavior for crossing rings. Selected hatch previews now share the resident fill/style/context path, including solid elevation and gradient/pattern transforms. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **STRETCH and Selection:** Crossing-box selection now hides/previews only objects that actually move, preserving other snap references. Shift-excluded grips/vertices stay excluded through preview and commit; fixed original geometry remains available for snapping. Fixed block/instance previews, fast-pointer overlays, rubber-band precision and release-build action creation. *(Contributed by [@gianlucafiore](https://github.com/gianlucafiore) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Snap Responsiveness and Correctness:** Intersection passes skip fill-only wires that cannot cross and enforce the query budget; center-snap arc carriers are indexed once; REGION boundaries and world-box queries use actual bounds. Throttled point snaps retain OTRACK and UCS Z-axis Ortho/Polar behavior; perpendicular candidates rank by distance and typed snap overrides respect command options. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@sclMAX](https://github.com/sclMAX) and [@Lukreynol01](https://github.com/Lukreynol01))*
* **Geometry Commands:** `OVERKILL` now compares normalized geometry within tolerance rather than DWG storage identity, handles reversed/overlapping lines and arcs, and reports checked/removed/modified counts. Fixed preselected JOIN across gaps, bulge EXTEND intersections, locked-layer replacement handles, TRIM/EXTEND option parsing and ellipse MIRROR/MINSERT explode regressions. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Camera and Viewport:** Pan/zoom/orbit reject non-finite camera updates and Zoom Extents skips NaN bounds. Zoom Extents/All/Object retain the intended pixel margin; orbit pivots on the surface beneath the pointer even for wire/fill geometry. A copied viewport gets its own clip boundary. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@insanedps](https://github.com/insanedps))*

#### Text, Dimensions & Multileaders

* **Dimension Editing and Annotation:** Editing existing dimension text now updates the active override and drops the stale picture block; fixed extension lines stop at the measured object. Rotated/mirrored dimensions relayout readable text, single-scale annotative dimensions use their picture, and per-scale DIMTOFL/DIMSOXD/DIMTIX/DIMTMOVE fit overrides are honored without changing stored dimensions. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@cmlad26](https://github.com/cmlad26))*
* **Dimension Rendering:** Fixed annotative text being scaled twice, annotative MLeaders incorrectly multiplying overall scale, angular measurements displayed from their radians value, dimension text width factors, DIMJUST placement, engineering inch trailing zeros, architectural tick width, origin arrowheads, `_None` user arrow blocks and radius/diameter picks inside blocks/viewports. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@ramox81](https://github.com/ramox81) and [@cmlad26](https://github.com/cmlad26))*
* **MLeader Compatibility:** Corrected text attachment values 5–8 and right-side attachment, landing underline origin/height/line, text and block-content mirroring, background-color masks, copied style remapping and style purge dependencies. *(Contributed by [@insanedps](https://github.com/insanedps), [@cmlad26](https://github.com/cmlad26), [@Jesus](https://github.com/Jeshuuu) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **MTEXT and Text Styles:** Corrected bare `\p` drawing-unit indents and tab-stop origins, SHX line spacing, bottom/middle ink attachment, editor preview orientation/contrast and `%%c`/`%%d`/`%%p` entry. Selecting a stroke font now clears the prior system-font override; TrueType bold/italic faces resolve from their family. *(Contributed by [@vandang890615](https://github.com/vandang890615), [@HakanSeven12](https://github.com/HakanSeven12), [@cmlad26](https://github.com/cmlad26) and [@ramox81](https://github.com/ramox81))*

* **Palettes and Properties:** Block gallery/palette caches no longer collide, build only needed previews and keep Recent/Favorites fallback previews. Floating palettes move and resize consistently while the viewport overlays keep pace; clipped property names show a tooltip. *(Contributed by [@MarcelP102](https://github.com/MarcelP102) and [@Jeshuuu](https://github.com/Jeshuuu))*
* **Command Input and Selection:** Command option buttons wrap instead of squeezing; selection cycling lists each object once and Escape closes the list; spreadsheet-pasted rows become separate points and tabs delimit X/Y. The crosshair remains visible for XLINE/RAY and hides when the pointer leaves the viewport. *(Contributed by [@Jesus](https://github.com/Jeshuuu), [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*
* **Layers, Properties and Links:** `LAYUNISO` restores only layers changed by `LAYISO`; hidden/xref-dependent symbols are retained; color dropdowns remain visible within scrollable palettes; transparency inputs keep focus and offer presets. * **Web and Other Stability:** Web drawing open evaluates fields as desktop does; web touch gestures use the platform clock. New drawings no longer lose entities to indistinguishable draw-depth labels; drawing reads can recover through the headless path; and DXF shape rotation is not applied twice. *(Contributed by [@megabrain-agent](https://github.com/megabrain-agent), [@HakanSeven12](https://github.com/HakanSeven12) and [@Jeshuuu](https://github.com/Jeshuuu))*
* **Performance:** Avoided full-document scans and rebuilds in INSERT block lookup, TRIM/EXTEND picks, HATCH startup/moves, snap candidates, constraint graph refresh, visual-style changes, repeated viewport solid meshes, palette previews and localization lookup. Reused nested xref documents and STEP assembly indexes; reduced automation JSON reply latency. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@KarimJerbi](https://github.com/KarimJerbi), [@Lukreynol01](https://github.com/Lukreynol01), [@schoeller](https://github.com/schoeller) and [@MarcelP102](https://github.com/MarcelP102))*
