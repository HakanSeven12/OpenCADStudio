# OpenCADStudio - Release v2026.45 (2026-11-08)

> **Summary:** Rebuilt the Layer Manager with in-drawing layer filters and a shared selection-filter engine; overhauled tables with cell styles, in-place editing and fill grips; added the Quad cursor menu with a plugin quad surface; expanded dynamic block authoring with Flip parameters, ordered action follow-ups and a Parameters Manager; advanced HATCH island/boundary handling, annotative scale and complex linetypes; added `BLOCKREPLACE`, `XPLODE`, `COMPARE`, `BURST`, `XBIND`, `PREVIEW`/`PUBLISH` and SVG import; and delivered broad performance work on TRIM, OSNAP/OTRACK, viewports and large drawings.

---

### 🌟 Notable Release Notes

* **Layer Manager and Filters:** Rebuilt the Layer Manager (filter tree beside the table, mockup rows and eyes, narrow pallet, columns, import from another drawing) with nested filters stored in the drawing, wildcard/property filters applied from the search, layer groups, `-LAYTRANS`, `-LAYERSTATE`/LAS and `XBIND`. *(Contributed by [@turbuczn](https://github.com/turbuczn), [@KarimJerbi](https://github.com/KarimJerbi) and [@insanedps](https://github.com/insanedps))*
* **Quick Select and FILTER:** Advanced selection filter with window, pattern help, states and live match count, saved filters in the drawing or a file, and `'FILTER`/`'QSELECT` inside a running command. *(Contributed by [@turbuczn](https://github.com/turbuczn))*
* **Tables Overhaul:** Table style cell styles with starting tables and insert-from-style; cell picking, grips, fill grips, a Table Cell ribbon tab, in-place editing, insert N rows/columns, break and fill; typed values checked against the cell's data type, with dates, currency/percent, thousands separators and two-digit year handling; wrapped text grows rows; `TABLECONTENT` kept in step. *(Contributed by [@ramox81](https://github.com/ramox81) and [@insanedps](https://github.com/insanedps))*
* **Quad Cursor Menu (API v15):** Entity-aware cursor menu with per-type panels and a plugin quad surface; plugin host hardened (NullHost document access, boot-ack observability, channel-ready dispatch). *(Contributed by [@schoeller](https://github.com/schoeller) and [@yztink](https://github.com/yztink))*
* **Dynamic Block Authoring:** Flip parameters end-to-end and their coupled caches migrated across edits; ordered action follow-ups with retained-branch evaluation; value sets for linear, XY, polar and rotation parameters; naming and label prompts at placement; lookup tables keep a blank next-value row; nested reference properties and visibility states edited in batches; the Parameters Manager edits rows and filters in place. *(Contributed by [@KarimJerbi](https://github.com/KarimJerbi), with Save Block crash recovery from [@Ch4rlos](https://github.com/Ch4rlos))*
* **HATCH and GRADIENT:** Command-line keywords, draw and path modes, shared arc options, a full Hatch panel, boundary path flags and forms, picked regions keep nested islands, island selection follows the circle start rule, Normal skips unflagged islands, ANGLE first in bundled patterns. *(Contributed by [@ramox81](https://github.com/ramox81) and [@jespinolao](https://github.com/jespinolao))*
* **Annotation Scale and Complex Linetypes:** Model-space linetypes honour `MSLTSCALE`; viewports honour `PSLTSCALE`; annotative attributes, dimensions and objects follow the current scale and the layout's own setting; a drawing opens at its saved scale; dashes keep their length in a scaled INSERT; multileader/dimension blocks, wide polylines and complex linetypes draw on block children; aligned linetypes fit every whole period per run. *(Contributed by [@silvioteston](https://github.com/silvioteston) and [@jespinolao](https://github.com/jespinolao))*
* **New Commands and Parity:** `BLOCKREPLACE` (retarget references of one block to another and rebuild the attributes), `XPLODE` (explode onto named colour, layer, linetype and lineweight), `COMPARE` (modified objects, settings and a CSV report), `BURST`, `XBIND`, `PREVIEW` (SVG), `PUBLISH`/`-PAGESETUP`/`EXPORTPDF`, `-LAYTRANS`/`-LAYERSTATE`, `-FIELD`, `SCALELISTEDIT`, `ANNOUPDATE`, `SELECT`/`SELECTPREVIOUS`, `LOGFILEON`/`LOGFILEOFF`, `JOIN` (collinear runs become a polyline; a line source reports the lines joined), `GROUP` rename/members at the command line, `OBJECTSCALE`, `SCALE`/`ROTATE` with a `Copy` option, `SPLFRAME` for spline-fit 3D polylines, `TEXTEDITMODE`/`DIMOVERRIDE` through the shared variable prompt, `DIMSCALE`/`DIMDEC`/`DIMLFAC` at the command line. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12), [@KarimJerbi](https://github.com/KarimJerbi) and [@ramox81](https://github.com/ramox81))*
* **Packaging and Releases:** Windows and Linux ARM64 and Intel macOS builds; managed mode for hosted installs with a start folder and SIGTERM recovery; the website's download page links the latest release's files; `.desktop` entry written when registering as a handler. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12) and [@Nozzit](https://github.com/Nozzit))*
* **Command-Line Drafting Parity:** `MEASUREGEOM` quick start, Area/Volume chains and `CLose`; `OFFSET` current-settings line, `Through`/`Erase`/`Layer`, `OFFSETGAPTYPE`, Exit/Multiple/Undo; `MATCHPROP` Settings window, named plot styles, centre-line preview and `MATCHMODE` above 32 bits; `REVCLOUD` chords and grips; `WIPEOUT` reference prompts and editable properties; a word after a variable's value prompt answers it; commands accepted from suggestions or typed with arguments are echoed; refused input prints as a plain line; solid geometry bounds are reported from `MEASURE`. *(Contributed by [@ramox81](https://github.com/ramox81) and [@mvanhorn](https://github.com/mvanhorn))*
* **Workspace, CUI and Tool Windows:** Customize User Interface with your own ribbon panels, a Classic workspace and Classic toolbars, Quick Access Toolbar customization and floating ribbon panels, dockable tool palettes, windows of their own for dialogs, keyboard-driven menus, and type-to-search in dropdown lists. *(Contributed by [@MarcelP102](https://github.com/MarcelP102), [@HakanSeven12](https://github.com/HakanSeven12) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Interaction and Editing:** Double-click edits in paper space and viewports; `Ctrl+Tab`/`Ctrl+Shift+Tab` switch drawings; image drop; softer shaded-view lighting; dialogs open beside another dialog. *(Contributed by [@HakanSeven12](https://github.com/HakanSeven12))*
* **Performance:** Spatial indexes in TRIM (cutter index, block boundaries, hover cuts), faster large-drawing interaction, viewport pointer latency and block-stub expansion, first click after a paste, OSNAP/OTRACK candidate hysteresis, faster `LAYOFF`, fewer re-tessellation passes. *(Contributed by [@gianlucafiore](https://github.com/gianlucafiore), [@martijn3BM](https://github.com/martijn3BM), [@mechpanos](https://github.com/mechpanos), [@Nozzit](https://github.com/Nozzit), [@insanedps](https://github.com/insanedps), [@HakanSeven12](https://github.com/HakanSeven12) and [@KarimJerbi](https://github.com/KarimJerbi))*

### 🚀 New Features

#### Tables

* **Table Cell Styles:** dialog, starting tables, insert-from-style; `TABLE <option>` as one line; cell data types with dates, currency/percent, separators and two-digit years; wrapped text grows rows. *([@ramox81](https://github.com/ramox81))*
* **Cell Grips and Editing:** row/column labels, ranges, Tab, in-place editing, N rows/columns placed without the editor, break and fill, top/left grips move the shared neighbour edge, Table Cell ribbon tab with nine alignments, grip resizes redraw. *([@insanedps](https://github.com/insanedps))*
* **`TABLECONTENT` Sync:** a table's copy follows its edits. *([@insanedps](https://github.com/insanedps))*

#### Layers and Selection

* **Layer Filters:** filters match on the shared engine; used/unused/selected-object scopes; `FILTER <name>` and saved filters in the drawing; nested tree; import layers from another drawing. *([@turbuczn](https://github.com/turbuczn))*
* **Layer Tools:** named layer sets and groups; `-LAYTRANS` standards mapping; `-LAYERSTATE` and LAS files; `LAYMRG` for several sources with a confirm; per-object `LAYOFF`; `LAYERFILTER`; `COPYTOLAYER` picks the destination after the objects; layer dropdowns reveal and highlight the selected object's layer; new layers take the picked layer's look; merge into a layer. *([@KarimJerbi](https://github.com/KarimJerbi), [@insanedps](https://github.com/insanedps), [@turbuczn](https://github.com/turbuczn), [@silvioteston](https://github.com/silvioteston) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Selection:** `SELECT`/`SELECTPREVIOUS` with a remembered set; group picks report the group; `STRETCH` Shift+click removes an object; `Ctrl` cycles a hot polyline grip; MTP/M2P hot grips; dragged grips stay put with a rubber band; spline-fit 2D and 3D dotted frames; `SPLFRAME` for spline-fit 3D polylines; `GROUPDISPLAYMODE` centre grip and extents box. *([@ramox81](https://github.com/ramox81), [@silvioteston](https://github.com/silvioteston) and [@insanedps](https://github.com/insanedps))*
* **Associative Arrays:** arrow grips for counts and spacings; COPY Array with a Fit option; a copied associative array is an array of its own — including copies of arrays of attributed blocks; zoom extents count items drawn as stubs. *([@insanedps](https://github.com/insanedps))*

#### Blocks and Attributes

* **Parameter Authoring:** value sets (None/List/Increment) for linear, XY, polar and rotation; name/label/description prompts at placement; a blank lookup row for the next value; chained actions named at authoring; ordered follow-up lists with retained branches; a written parameter value moves the reference it was set on. *([@KarimJerbi](https://github.com/KarimJerbi))*
* **Flip Parameters:** validated Flip targets, transported axes, reflection frames, coupled Flip evaluation and cache migration. *([@KarimJerbi](https://github.com/KarimJerbi))*
* **Parameters Manager:** docks above the authoring palettes, opens from the command and ribbon, edits rows in place, filter/search narrows the list, header column menu, glyph per measured kind, expression filter; lookup and visibility rows stay listed while the graph will not take an edit. *([@KarimJerbi](https://github.com/KarimJerbi))*
* **Attributes:** one form when `ATTDIA` is on; `-ATTEDIT` handle and tag rename; swap a string in values from the command line; INSERT attribute visibility under `ATTMODE`; values read as children with their own geometry. *([@KarimJerbi](https://github.com/KarimJerbi) and [@dhy365-creator](https://github.com/dhy365-creator))*
* **Copies and Explode:** copies of an array of attributed blocks are arrays of their own; `BURST` keeps attribute values as text; `EXPLODE` breaks multilines into their lines; `ATTREDEF` redefines a block's attributes from a reference and stays on the command line and out of the Insert quad. *([@insanedps](https://github.com/insanedps), [@KarimJerbi](https://github.com/KarimJerbi) and [@travisjhughes](https://github.com/travisjhughes))*
* **`BLOCKREPLACE` and `XPLODE`:** point the references of one block at another definition, which rebuild the attributes the new definition declares; explode a selection onto named colour, layer, linetype and lineweight properties. *([@KarimJerbi](https://github.com/KarimJerbi))*

#### Viewing, Sheets and Interchange

* **Viewports:** VPORTS configuration list, three-viewport layouts, hover outline, `VPMAX`/`VPMIN`, named VPORTS configurations, `VPSCALE`/`VPLOCK`, metre drawings restore physical viewport scales. *([@insanedps](https://github.com/insanedps), [@KarimJerbi](https://github.com/KarimJerbi), [@jespinolao](https://github.com/jespinolao) and [@gianlucafiore](https://github.com/gianlucafiore))*
* **Sheets and Plot:** `PREVIEW` renders the page as SVG; `-PAGESETUP` named setups; `PUBLISH` named sheets into one PDF; `EXPORTPDF` named file per layout or all; plot to PDF folder, naming and DPI; annotation scale applied to model-space dash patterns; literal `1:1` paper label preferred. *([@KarimJerbi](https://github.com/KarimJerbi), [@HakanSeven12](https://github.com/HakanSeven12), [@silvioteston](https://github.com/silvioteston) and [@gianlucafiore](https://github.com/gianlucafiore))*
* **MLEADER and Dims:** MLEADER labels stay precise far from the origin; a leader of type None draws only its content; text background fill switches with code 292; multileader balloons and annotative dimension text follow the annotation scale (`SETVAR` exposes annotation scale, visibility and hatch variables); `REVCLOUD` path-length chords, settings, grips and a Revision Cloud split button on Annotate > Markup; `DIMSCALE`, `DIMDEC` and `DIMLFAC` at the command line. *([@jespinolao](https://github.com/jespinolao), [@ramox81](https://github.com/ramox81), [@HakanSeven12](https://github.com/HakanSeven12), [@silvioteston](https://github.com/silvioteston) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Interchange and Save:** SVG/SVGZ import (`SVGIN`, drag and drop); Copy as SVG; `.ifccad` preferred over `.ifcx` (still supported); autosave copies live in a folder of their own; lossy DXF export prunes dangling references; `BEDIT` Save Block writes its recovery copy at once; DGN V8 reads every model element stream. Block previews restored for transform, placement and clipboard commands. *([@felixriestra](https://github.com/felixriestra), [@HakanSeven12](https://github.com/HakanSeven12), [@BjornFidder](https://github.com/BjornFidder), [@Ch4rlos](https://github.com/Ch4rlos), [@silvioteston](https://github.com/silvioteston) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Fields and Text:** `Ctrl+F` inserts a field at the caret; Insert Field into a formula; fields of fields reopen; `-FIELD` script form; MTEXT editor follows the text style and names where each value comes from; two-column text style manager with a live preview and usage; the font list sits under its field and is coloured; the Apply summary lists every changed style with counts; full symbol list in two columns; typed `\U+XXXX`; paragraph spacing; `\C256` runs in the layer colour; an SHX font's missing character draws its stand-in; a written line stays in its drawing; SHX big fonts pick the code page; arc-aligned text drawn as text. *([@ftaski](https://github.com/ftaski), [@jespinolao](https://github.com/jespinolao), [@turbuczn](https://github.com/turbuczn), [@KarimJerbi](https://github.com/KarimJerbi), [@HakanSeven12](https://github.com/HakanSeven12) and [@ramox81](https://github.com/ramox81))*

#### Automation and MCP

* **Node Graph:** nodes for every object the drawing commands make — Hatch, Multiline, Multileader, Helix, Radius/Diameter dimensions, Rectangle, Polygon, Donut, Revision Cloud, Modify and Model — plus Objects By Type. *([@HakanSeven12](https://github.com/HakanSeven12))*
* **MCP:** `entities_create` gives Inserts attribute values by tag; `set_properties` takes colour as a number or RGB; matchprop_settings schema digest; scripted attribute placements answered in form; attribute values read as children with their own geometry. *([@silvioteston](https://github.com/silvioteston) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Registry and Docs:** Commands Reference; Terén plugin in the registry; 3D solid icons, VAR badge, command synonym and alias icon resolution. *([@felixriestra](https://github.com/felixriestra), [@pabloxbezx](https://github.com/pabloxbezx) and [@HakanSeven12](https://github.com/HakanSeven12))*
