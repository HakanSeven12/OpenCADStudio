# OpenCADStudio - Release v2026.46 (2026-11-15)

> **Summary:** Redesigned the UI kit, icons, menus, dropdowns, document tabs, Start page and added the Studio Dark theme; delivered `GEOGRAPHICLOCATION`, automatic `PDFATTACH` GeoPDF placement, Geospatial PDF export and complete `ETRANSMIT` ZIP packaging; overhauled annotation scaling (`OBJECTSCALE`) and the Dimension, Multileader and Text Style managers alongside Big5 SHX decoding and `EATTEDIT`/`ATTSYNC`; deepened Civil 3D object decoding, dynamic block parameter grip workflows and table formulas/`PASTESPEC` data links; added the `LINETYPE` manager, `ASSISTANT` AI chat pallet, `?embed=1` web bridge, Linux SpaceMouse, built-in `HELP` command wiki and Plugin API v19–v23 with batched Python `ocs` primitives; and shipped broad performance, LRU cache-budget, selection and `mimalloc` improvements across the engine.

### 🚀 New Features

#### Annotation Scaling, Dimensions, Text & Multileader Styles

* **Annotation Scaling (`#2749`, `#2794`, `#2960`):** `OBJECTSCALE` dialog lists, adds and removes object scales, promoting the next scale when the default is removed; Scale List window reorders, resets to unit scales in use and honours 6-decimal ratios; Properties shows the active scale and dims other representations; annotation monitor badge marks objects; and the app prompts for an annotation scale before a session's first annotative text (outside scripts). *([@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Dimension Style Manager & `DIM` Tools (`#2899`, `#2942`, `#2945`):** Full Dimension Style Manager with `New`, `Modify`/`Override` and `Compare` windows; `-DIMSTYLE` renames, deletes, compares variables between two styles and lists/edits individual dimvars; `DIMOVERRIDE` lists a dimension's overrides; `DIMEDIT` Oblique turns extension lines to the entered angle; `\X` in dimension text places subsequent text below the line; new drawings seed an `Annotative` dimension style; and renaming/deleting a style carries its family members along. *([@ramox81](https://github.com/ramox81), [@KarimJerbi](https://github.com/KarimJerbi) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **Multileader Style Manager & `MLEADER` (`#2884`, `#2941`, `#2943`):** `New` and `Modify` faces with live real-size preview, predefined blocks with tags and Integral arrowhead arcs, `.lin` linetype reloading and one undo step per edit; content-first block `MLEADER` places its centre, asks attribute values, then places the arrowhead; exposes leader count and vertex lists. *([@ramox81](https://github.com/ramox81) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Text Style Manager & Big Fonts (`#2769`, `#2952`, `#2959`):** Alphabetical style list, paging, measured name rules, notices, orientation undo in `-STYLE`, new drawings seeded with `Arial Standard` and `Annotative` styles; dedicated SHX Big Font picker listing drawing, adjacent and configured font folders, plus corrected Big5 (`ansi_950`) decoding and `chinese.shx` aliasing. *([@ramox81](https://github.com/ramox81), [@tutumomo](https://github.com/tutumomo) and [@HakanSeven12](https://github.com/HakanSeven12))*
* **In-Place MTEXT & Attributes (`#2947`, `#2990`):** Wheel zooms over text being edited in place; `EATTEDIT` opens the attribute editor directly on selected references or pick; named `ATTSYNC <block>` synchronises without prompting; `ATTOUT`/`ATTIN` export and import block attributes in a text file; and Attribute forms paginate 15 rows per page with a sticky footer and `dialog_page` automation. *([@insanedps](https://github.com/insanedps), [@KarimJerbi](https://github.com/KarimJerbi), [@ramox81](https://github.com/ramox81) and [@HakanSeven12](https://github.com/HakanSeven12))*

* **Snaps, Dynamic UCS & 3D Modeling (`#2793`, `#2797`, `#3032`):** Shift+letter temporary snap or tracking override at point prompts, typed distance along Z during Z-tracking, Dynamic UCS hover outline on the solid face it would align to, `EXTRUDE` along UCS Z with a UCS Z grip, shaded solid face click selection, `AUTOCONSTRAIN` reporting applied constraints by kind, `EXPLODE` turning associative arrays into copies of source objects, and `VPLAYER` per-viewport colour, linetype, lineweight and transparency overrides. *([@ramox81](https://github.com/ramox81), [@HakanSeven12](https://github.com/HakanSeven12) and [@KarimJerbi](https://github.com/KarimJerbi))*
