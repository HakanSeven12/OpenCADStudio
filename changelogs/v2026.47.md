# OpenCADStudio - Release v2026.47 (2026-11-22)

> **Summary:** Migrated 3D modeling onto Solidcore (`solidcore_record` / `solidcore-ops`) with the new **Surface** ribbon tab, `SOLIDEDIT`/`IMPRINT`/`XEDGES`, exact `STEPOUT` B-rep export, display LODs (½ and ¼), `VISUALSTYLES` Manager and shaded/hidden-line 3D plotting; added `EXPORTDWF` and DWF raster image/draw-order support, `ADCENTER` Design Center, `INSERTOBJ` document OLE packaging, `PNGOUT`/`JPGOUT`/`BMPOUT`/`TIFOUT`, `POPMENU`, `ADDVERTEX`/`DELVERTEX`, `GAPCHECK`, `ALIGNSPACE`, and clicked-box `Fence`/`WPolygon`/`CPolygon` selection; expanded Civil 3D authoring (`CREATEPOINTS`, `CREATEALIGNMENT`, `CREATESURFACE`, `CREATEPROFILE`, `CREATECORRIDOR`, `CREATEPARCEL`, `CREATEPIPENETWORK`, `CREATEASSEMBLY`, `CREATEINTERSECTION`, `CREATECURBRETURN`) and read ops; added the contextual **Text Editor** ribbon tab, `FIND` & `EATTEDIT` overhauls, formula operand chips, and `Table Style`/`Text Style` card layouts; shipped Plugin API v24–v27 (`on_undo_step`, plugin AI tools via MCP `plugin_call`, `CustomPropertiesSet`, `DocumentChangedDelta`, `InteractiveInputKind::TextInput`, `PanelScene` S01, `PanelStyle::Form`, Python `request_drag`); offloaded 15+ blocking/panic-prone file-read paths to background workers with a `update_root` panic guard; and delivered major performance and memory gains across `--low-memory`, `mimalloc` on Linux/macOS, 2D rollover highlight caching, instanced solid outlines, resident wire reaper/sharing/orbit culling, incremental block/undo-budget invalidation, and layout viewport LRU caps.

### ⚡ Performance

* **Selection and rollover (#3278, #3384).** Separate hover and selection generations keep rollover and marquee updates from rebuilding committed selection GPU buffers. Cache selectable groups, per-frame viewport interaction data, and hovered text uploads. Reuse the constant buffer for dense highlights, keep 2D rollover out of base render caches, and scan candidates in parallel up to `HOVER_CANDIDATE_CAP`. Limit marquee previews to `SELECTIONPREVIEWLIMIT` and defer Properties rebuilds for large selections by one frame. *([@emrahoksak](https://github.com/emrahoksak))*
* **Memory (#3387).** Add read-only DWG viewing with `--low-memory` and enable `mimalloc` on Linux and macOS. Free evicted resident wire sets on a dedicated thread and share cold `WireGeom` vectors via `Arc`. Browser `AUTOSAVE` and `SAVEALL` process one document at a time. *([@emrahoksak](https://github.com/emrahoksak) and [@KarimJerbi](https://github.com/KarimJerbi))*
* **Scene and layout caches.** Narrow cache invalidation for blocks, `BEDIT`, properties, the clipboard, and the layer tree. Cull by Z bounds during 3D orbit, instance outlines of moved block solids, and simplify distant solid edges. Bound per-viewport resident, split, and plot-style LRU caches. Deduplicate GPU census handles, track undo memory incrementally, and cache block solid snap maps per geometry epoch. Speed up `LAYWALK` on open, keep wire arenas active with marker wires, and patch multiple additions into resident wire sets. Resolve tessellation context once per edit preview and rescale dynamic dimensions through restyling. *([@KarimJerbi](https://github.com/KarimJerbi), [@jespinolao](https://github.com/jespinolao), [@travisjhughes](https://github.com/travisjhughes), [@HakanSeven12](https://github.com/HakanSeven12), and [@insanedps](https://github.com/insanedps))*
* **Raster layouts and zoom.** Share decoded pixels and GPU textures across viewports to prevent raster-heavy layouts from hanging. Each zoom step redraws underlay and OLE rasters once on a worker and updates them without invalidating scene geometry. Paper-space underlays follow sheet zoom. *([@HakanSeven12](https://github.com/HakanSeven12), [@emrahoksak](https://github.com/emrahoksak), [@travisjhughes](https://github.com/travisjhughes), and [@jespinolao](https://github.com/jespinolao))*
* **File I/O and responsiveness.** Reuse the initial point-cloud read and get underlay page sizes on first load. Native saves await the writer without blocking the executor. Control connections reuse a bounded worker pool. Settings are written only when their serialized values change. *([@travisjhughes](https://github.com/travisjhughes), [@KarimJerbi](https://github.com/KarimJerbi), and [@HakanSeven12](https://github.com/HakanSeven12))*
