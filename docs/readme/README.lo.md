## ພາບລວມ

Open CAD Studio ເປັນແອັບພລິເຄຊັນຂ້າມແພລັດຟອມ ສຳລັບການແຕ້ມແບບທາງເທັກນິກ, ການຈັດໜ້າເລເອົາຕ໌ ແລະ ການສ້າງແບບຈຳລອງວັດຖຸຕັນ. ມັນອ່ານ ແລະ ຂຽນແບບແຕ້ມ DWG ແລະ DXF ໂດຍກົງ, ແລະ ລຸ້ນເດັສທັອບກັບລຸ້ນບຣາວເຊີໃຊ້ແກນການແກ້ໄຂດຽວກັນ.

ໂຄງການນີ້ກຳລັງຖືກພັດທະນາຢ່າງຕໍ່ເນື່ອງ. ກະລຸນາສຳຮອງແບບແຕ້ມທີ່ສຳຄັນໄວ້ສະເໝີ ແລະ ລາຍງານບັນຫາທີ່ສາມາດເຮັດຊ້ຳໄດ້ຜ່ານ [GitHub Issues](https://github.com/HakanSeven12/OpenCADStudio/issues).

## ຈຸດເດັ່ນ

- **ເຮັດວຽກກັບແບບແຕ້ມໂດຍກົງ** — ເປີດ, ແກ້ໄຂ, ກູ້ຄືນ ແລະ ບັນທຶກໄຟລ໌ DWG ແລະ DXF ໂດຍບໍ່ຕ້ອງໃຊ້ບໍລິການແປງໄຟລ໌.
- **ການແຕ້ມ 2D ທີ່ຊັດເຈນ** — ເສັ້ນ, ໂພລີລາຍ, ເສັ້ນໂຄ້ງ, ເສັ້ນສະພລາຍ, ລວດລາຍແຮເງົາ, ສະແນັບວັດຖຸ, ການຕິດຕາມ, ເລເຢີ, ບລັອກ ແລະ ການອ້າງອີງພາຍນອກ.
- **ເຄື່ອງມືເຮັດເອກະສານ** — ຂໍ້ຄວາມ, ຂະໜາດ, ເສັ້ນຊີ້, ຄ່າຄວາມຄາດເຄື່ອນ, ຕາຕະລາງ, ພື້ນທີ່ໂມເດວ, ພື້ນທີ່ເຈ້ຍ, ວິວພອດ ແລະ ຮູບແບບການພລັອດ.
- **ການສ້າງແບບຈຳລອງ 3D ດ້ວຍເຄີເນວ** — ຮູບຊົງຕັນພື້ນຖານ, ດຶງຢືດ (Extrude), ໝູນກວາດ (Revolve), ກວາດຕາມເສັ້ນ (Sweep), ລັອບ (Loft), ການດຳເນີນການ Boolean ແລະ ການແບ່ງພື້ນຜິວວັດຖຸ ACIS.
- **ການສະແດງຜົນດ້ວຍ GPU** — ວິວພອດ 2D ແລະ 3D ທີ່ເລັ່ງດ້ວຍ `wgpu` ພ້ອມກ້ອງແບບອໍໂທກຣາຟິກ ແລະ ແບບເພີສເປັກທີບ.
- **ຂະຫຍາຍການເຮັດວຽກໄດ້** — ປລັກອິນພາຍໃນເຄື່ອງ, ສະຄຣິບຄຳສັ່ງ, ການແປງໄຟລ໌ແບບບໍ່ມີໜ້າຕ່າງ ແລະ API ອັດຕະໂນມັດແບບ JSON ຕໍ່ແຖວ.

## ເດັສທັອບ ຫຼື ເວັບ?

ໃຊ້ [ແອັບເວັບ](https://www.opencadstudio.com) ເພື່ອເລີ່ມໃຊ້ທັນທີໂດຍບໍ່ຕ້ອງຕິດຕັ້ງ. ແບບແຕ້ມຈະຖືກເລືອກຜ່ານບຣາວເຊີ ແລະ ບັນທຶກເປັນໄຟລ໌ດາວໂຫຼດໃນເຄື່ອງ.

ໃຊ້ແອັບເດັສທັອບສຳລັບການຜູກໄຟລ໌ກັບລະບົບ, ຮູບຕົວຢ່າງໃນຕົວຈັດການໄຟລ໌, ການພິມຂອງລະບົບ, ການສົ່ງອອກ PDF, ປລັກອິນພາຍນອກ, ສະຄຣິບຄຳສັ່ງ ແລະ ການເຮັດວຽກອັດຕະໂນມັດແບບບໍ່ມີໜ້າຕ່າງ. ມີລຸ້ນສຳລັບ Windows, Linux ແລະ macOS ທີ່ໃຊ້ Apple Silicon.

## ການຕິດຕັ້ງ

ດາວໂຫຼດແພັກເກດທັງໝົດທີ່ໃໝ່ສຸດຈາກ [ລຸ້ນລ່າສຸດ](https://github.com/HakanSeven12/OpenCADStudio/releases/latest).

### Windows

ເລືອກແພັກເກດ x86-64 ທີ່ມີລາຍເຊັນອັນໃດອັນໜຶ່ງ:

- `OpenCADStudio-*-windows-x86_64-installer.msi` — ຕົວຕິດຕັ້ງທີ່ແນະນຳ ພ້ອມທາງລັດໃນເມນູ Start, ການຜູກໄຟລ໌ DWG/DXF ແລະ ຮູບຕົວຢ່າງແບບແຕ້ມ.
- `OpenCADStudio-*-windows-x86_64-portable.exe` — ແອັບແບບພົກພາທີ່ບໍ່ຕ້ອງຕິດຕັ້ງ.

### Linux

ດາວໂຫຼດໄຟລ໌ AppImage x86-64, ເຮັດໃຫ້ມັນສາມາດເອີ້ນໃຊ້ໄດ້ ແລະ ເປີດມັນ:

```bash
chmod +x OpenCADStudio-*-linux-x86_64.AppImage
./OpenCADStudio-*-linux-x86_64.AppImage
```

### macOS

ແພັກເກດ macOS ທີ່ເຜີຍແຜ່ຮອງຮັບ Apple Silicon:

1. ດາວໂຫຼດ `OpenCADStudio-*-macos-arm64.dmg`.
2. ເປີດດິສອິມເມດ ແລະ ລາກ `OpenCADStudio.app` ໄປໃສ່ໂຟນເດີ **Applications**.
3. ຖ້າ Gatekeeper ບລັອກການເປີດຄັ້ງທຳອິດ, ໃຫ້ອະນຸມັດແອັບໃນ **System Settings → Privacy & Security**.

ແອັບມີລາຍເຊັນແບບຊົ່ວຄາວ ແຕ່ປະຈຸບັນຍັງບໍ່ໄດ້ຮັບການຮັບຮອງ (notarize) ຈາກ Apple.

## ການສ້າງຈາກໂຄດຕົ້ນສະບັບ

### ເດັສທັອບ

ສິ່ງທີ່ຕ້ອງມີ:

- Git
- ຊຸດເຄື່ອງມື Rust ລຸ້ນສະຖຽນລ່າສຸດ
- ໄລບຣາຣີພັດທະນາດ້ານກຣາຟິກ ແລະ ຟອນຂອງແຕ່ລະແພລັດຟອມ

ໃນ Ubuntu ຫຼື Debian, ໃຫ້ຕິດຕັ້ງສ່ວນປະກອບທີ່ຈຳເປັນ:

```bash
sudo apt update
sudo apt install libgl1-mesa-dev libx11-dev libxcursor-dev libxi-dev \
  libxrandr-dev libxkbcommon-dev libwayland-dev libfontconfig1-dev \
  libfreetype6-dev
```

ຈາກນັ້ນສ້າງໂປຣແກຣມ:

```bash
git clone https://github.com/HakanSeven12/OpenCADStudio.git
cd OpenCADStudio
cargo build --release --bin OpenCADStudio
```

ໄຟລ໌ໂປຣແກຣມຈະຖືກຂຽນໄວ້ທີ່ `target/release/OpenCADStudio` (ໃນ Windows ແມ່ນ `OpenCADStudio.exe`).

### ເວັບ

ຕິດຕັ້ງເປົ້າໝາຍ WebAssembly ແລະ ເຄື່ອງມືສ້າງໂປຣແກຣມຄັ້ງດຽວ:

```bash
rustup target add wasm32-unknown-unknown
cargo install trunk wasm-bindgen-cli
```

ເລີ່ມເຊີບເວີພັດທະນາ:

```bash
trunk serve
```

## ການເຮັດວຽກອັດຕະໂນມັດ

ໂປຣແກຣມເດັສທັອບຮອງຮັບການແປງໄຟລ໌ຄັ້ງດຽວ ແລະ ເຊີບເວີແບບບໍ່ມີໜ້າຕ່າງທີ່ເຮັດວຽກຕໍ່ເນື່ອງ:

```bash
OpenCADStudio --export input.dwg output.dxf
OpenCADStudio --serve
OpenCADStudio --serve --port 4242
OpenCADStudio --mcp
```

ເຊີບເວີແລກປ່ຽນວັດຖຸ JSON ໜຶ່ງອັນຕໍ່ແຖວຜ່ານ stdin/stdout ຫຼື TCP socket ພາຍໃນເຄື່ອງ. ເບິ່ງ [ຄູ່ມືການເຮັດວຽກອັດຕະໂນມັດ](../automation/README.md).
