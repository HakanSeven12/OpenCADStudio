summary: Turns on orbit mode so that dragging in the drawing area rotates the 3D view.
related: PAN, ZOOM, NAVVCUBE
ribbon: View tab › Navigate panel
---

## Usage
1. Start the command. The cursor changes to the orbit cursor.
2. Drag in the drawing area to rotate the view.
3. Press Esc to leave orbit mode.

## Notes
- Starting another command also ends orbit mode.
- Only the view changes; no objects are modified.
- A paper-space sheet stays in top view; orbit has no effect on it.
