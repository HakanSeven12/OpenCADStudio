## Usage
1. Start the command. The About dialog opens.
2. Read the details, or click **Copy Info** to copy them to the clipboard.

## Notes
- The dialog shows the version, platform, architecture, build, commit date and build profile.
- It also lists the CPU, the amount of RAM and the graphics card with its graphics backend.
- Copied details are useful when you report a problem.
