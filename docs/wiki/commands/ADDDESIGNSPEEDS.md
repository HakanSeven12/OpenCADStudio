---
summary: Adds design speeds to an alignment.
related: CREATEALIGNMENT, ADDSTATIONEQUATIONS
---

## Usage
1. Select an alignment.
2. Specify each design speed as station,speed (for example 0,60 then 250,80); press Enter to end.

## Notes
- Each speed applies from its station on, until the next one.
- The stations must lie on the alignment.
- The alignment is written again, so it must be one OpenCAD Studio can write again.
