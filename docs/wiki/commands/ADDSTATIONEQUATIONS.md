---
summary: Adds station equations to an alignment.
related: CREATEALIGNMENT, ADDDESIGNSPEEDS
---

## Usage
1. Select an alignment.
2. Specify each equation as station,station ahead (for example 120,1000); press Enter to end.
3. Press Enter, or first set **Direction**: whether the stations ahead increase (the default) or decrease.

## Notes
- The station is where the equation lies, measured along the alignment before any equation; the station back is what the equations before it give there.
- New equations must come after the alignment's own.
- The alignment is written again, so it must be one OpenCAD Studio can write again.
