## Usage
1. Select a multileader, or start the command and select one.
2. Specify the leader arrowhead location. A new leader line is added to the multileader.
3. Repeat to add more leaders.
4. Press Enter to finish.

## Options
| Option | What it does |
|---|---|
| **Remove leaders** (`R`) | Switches to removing leaders, as in [`AIMLEADEREDITREMOVE`](AIMLEADEREDITREMOVE-Command). |

## Notes
- A rubber band from the cursor shows where the new leader joins the multileader.
- The command is also on the right-click menu when one multileader is selected.
- If you pick an object that is not a multileader, the command reports it.
- All changes are applied together when you press Enter.
