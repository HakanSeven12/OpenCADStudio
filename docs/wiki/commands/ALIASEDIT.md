## Usage
1. Start the command. The **Command Aliases** dialog opens with every alias and its command.
2. Edit an alias or command in the list, or click the trash button on a row to delete it.
3. To add one, click **+ Add alias**, type the alias and the command, and accept the row. Press Esc to cancel the new row.
4. Click **Apply** to save, or **Apply & Exit** to save and close.

## Notes
- An alias used twice turns red, and a warning names the command that already uses it.
- A command that does not exist is shown as an unknown command.
- **Reset to default** restores the default aliases after you confirm. Your own aliases are lost.
- **Export...** saves the aliases to a file. **Import PGP…** reads aliases from a PGP alias file.
- Closing with unsaved changes asks whether to discard them.
- Keyboard shortcuts are edited separately in [`CUI`](CUI-Command).
