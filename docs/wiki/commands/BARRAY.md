---
summary: In the Block Editor, adds an array action to a parameter of a dynamic block.
related: BACTION, BPARAMETER, BEDIT
---

`BARRAY` runs [`BACTION`](BACTION-Command) with the **Array** action type already chosen.

## Usage
1. Select a parameter endpoint or enter its name. Linear, polar and XY parameters can be used.
2. Select objects for the action, then press Enter.
3. Specify the distance between columns. For an XY parameter, also specify the distance between rows. For a polar parameter, specify the distance between items.
4. Specify action marker location.

## Notes
- The command works only while a block is open in the Block Editor.
