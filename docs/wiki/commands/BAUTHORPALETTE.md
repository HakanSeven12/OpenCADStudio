## Usage
1. Run the command. If the Authoring Palettes panel is closed, it opens. If it is already open, it closes.

## Notes
- The panel has four tabs:
  - **Parameters**: Point, Linear, Polar, XY, Rotation, Alignment, Flip, Visibility, Lookup and Basepoint parameters.
  - **Actions**: Move, Scale, Stretch, Polar Stretch, Rotate, Flip, Array, Lookup and Block Properties Table.
  - **Parameter Sets**: a parameter together with its matching action, for example Linear Move, Polar Stretch Pair or XY Array Box Set.
  - **Constraints**: the geometric and dimensional constraint tools.
- Each row shows a short description. A row is greyed out, with the reason as its description, when the tool cannot be used yet, for example when no block is open in the Block Editor or a required parameter is missing.
- You can run this command while another command is active; the running command keeps going.
