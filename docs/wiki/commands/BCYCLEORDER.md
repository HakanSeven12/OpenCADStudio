## Usage
1. Run the command in the Block Editor. The **Grip Cycle Order** dialog opens.
2. The list shows each grip with its parameter name, type and location, and whether it takes part in cycling.
3. Select a row and use **Move Up** or **Move Down** to change its place in the order.
4. Use **Cycling** to switch the selected grip on or off for cycling.
5. Click **Apply** to save the order, or **Cancel** to close without changes.

## Notes
- The command works only in the Block Editor.
- If the parameters change while the dialog is open, **Apply** is refused and you are asked to reopen the command.
- The change can be undone.
