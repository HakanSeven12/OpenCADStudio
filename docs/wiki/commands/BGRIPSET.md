## Usage
1. Click a definition point or the label of a parameter, or type the parameter's name. If a parameter is already selected, this step is skipped.
2. Enter the number of grips, or type **Reposition**. Only the counts the parameter supports are offered.
3. Press Escape to cancel.

## Options
| Option | What it does |
|---|---|
| **0**, **1**, **2**, **4** | Sets the number of grips of the parameter. Which counts appear depends on the parameter type. |
| **Reposition** (`R`) | Moves the parameter's existing grips back to their default locations. |

## Notes
- The command works only in the Block Editor.
- If the block has no parameter with grips, you are asked to add a parameter first.
- The change can be undone.
