---
summary: Opens or closes the Parameters Manager panel, which lists the parameters of the block open in the Block Editor.
related: BPARAMETERSCLOSE, PARAMETERS, BPARAMETER, BEDIT
---

## Usage
1. Run the command. If the Parameters Manager is closed, it opens. If it is already open, it closes.

## Notes
- The panel lists the parameters of the block that is open in the Block Editor, with the columns **Name**, **Expression**, **Value**, **Type**, **Show**, **Order** and **Description**. Outside the Block Editor the list is empty.
- You can edit values and expressions in the list, filter it, and right-click the header to show or hide columns.
- You can run this command while another command is active; the running command keeps going.
- In the Block Editor, [`PARAMETERS`](PARAMETERS-Command) opens the same panel.
