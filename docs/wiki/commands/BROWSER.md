---
summary: Opens or closes the Browser panel, an outline of the origin planes, the open sketch and the solid bodies of the drawing.
related: CREATESKETCH, FINISHSKETCH
---

## Usage
1. Run the command. If the Browser is closed, it opens and docks. If it is open, it closes.

## Notes
- The panel has three sections:
  - **Origin planes**: XY, XZ and YZ. Click one to start a sketch on that plane.
  - **Sketch**: the open sketch, if any. Click it to finish the sketch.
  - **Bodies**: every 3D solid in the drawing, named by the operation that created it when the drawing records it. Click one to select it.
- The list is an outline only. It is not an editable feature history; changing an earlier entry does not rebuild later ones.
