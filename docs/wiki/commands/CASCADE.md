## Usage
1. Run `CASCADE`. There are no prompts.
2. The view is divided into four viewports of the same size.

## Notes
- `CASCADE` is a shortcut for the four-viewport configuration of [`VPORTS`](VPORTS-Command). It does not arrange drawing windows.
- In the Model tab it splits the model view into four panes. In a layout it creates four layout viewports.
- To return to one viewport, use [`VPORTS`](VPORTS-Command) with the Single option.
