## Usage
1. Run `CLEANSCREEN`. The ribbon and the docked panels are hidden.
2. Run `CLEANSCREEN` again to show them.

## Notes
- The menu bar and the status bar stay visible, so commands stay within reach and you can turn the mode off again.
- A panel you open while clean screen is on (for example Properties) is shown on top of the full drawing.
- The **Clean Screen** button on the status bar does the same.
- Typing `CLEANSCREENON` or `CLEANSCREENOFF` turns the mode on or off without toggling.
