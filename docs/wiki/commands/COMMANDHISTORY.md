---
summary: Shows or hides the Command History pallet, which lists the text of the command line.
related: COMMANDLINE, COMMANDLINETOGGLE
---

## Usage
1. Type `COMMANDHISTORY`. The Command History pallet opens in its own window.
2. Run it again to close the pallet.

## Notes
- The pallet shows the command-line history as text, newest lines at the bottom.
- In the web app the pallet floats in the middle of the screen instead of opening a separate window.
- The keyboard shortcut for this command opens the history list above the command line rather than the pallet.
