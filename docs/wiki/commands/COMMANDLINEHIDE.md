---
summary: Hides the command line.
related: COMMANDLINE, COMMANDLINETOGGLE
---

## Usage
1. Type `COMMANDLINEHIDE`. The command line disappears.

## Notes
- You can still type commands while it is hidden. Dynamic Input shows the prompt and what you type at the cursor.
- The choice is kept for your next session.
- Run [`COMMANDLINE`](COMMANDLINE-Command) to show it again.
