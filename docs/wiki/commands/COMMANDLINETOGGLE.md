---
summary: Shows the command line if it is hidden, and hides it if it is shown.
related: COMMANDLINE, COMMANDLINEHIDE
---

## Usage
1. Run `COMMANDLINETOGGLE`. The command line switches between shown and hidden.

## Notes
- While the command line is hidden you can still type commands. Dynamic Input shows the prompt and your typing at the cursor.
- The choice is kept for your next session.
