summary: Shows, hides or resets the geometric constraint bars of the selected objects.
related: GCSHOW, GCHIDE, GCSHOWALL, AUTOCONSTRAIN, DELCONSTRAINT
---

## Usage
1. Select objects, then press Enter. If you selected objects first, this step is skipped.
2. Type an option, or press Enter for **Show**.

## Options
| Option | What it does |
|---|---|
| **Show** (`S`) | Shows the constraint bars of the selected objects. |
| **Hide** (`H`) | Hides the constraint bars of the selected objects. |
| **Reset** (`R`) | Makes the constraint bars of the selected objects visible again and reports how many were reset. |

## Notes
- Only geometric constraint bars are affected. Dimensional constraints are not.
