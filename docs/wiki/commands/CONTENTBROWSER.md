## Usage
1. Run `CONTENTBROWSER`. The command line lists the drawing's blocks and layers, each with a count.

## Notes
- Nothing opens; the command only prints the two lists. [`ADCENTER`](ADCENTER-Command) does the same.
- Blocks shows "(none)" when the drawing has no blocks of its own.
