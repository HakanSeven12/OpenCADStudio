---
summary: Converts POINT objects into COGO points, asking a description for each.
related: CREATEPOINTS, CREATEBLOCKSFROMPOINTS
---

## Usage
1. Select POINT objects and press Enter.
2. For each point, type a description, or press Enter (or type `.`) for none.
3. Select more points, or press Enter to end.

## Notes
- Each COGO point takes the POINT's x, y and z; the POINT is erased.
- The command undoes as one step.
