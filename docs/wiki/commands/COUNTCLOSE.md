---
summary: Leaves count mode and returns the drawing to its normal display.
related: COUNT, COUNTLISTCLOSE
---

## Usage
1. Run `COUNTCLOSE`. The count toolbar closes and the highlights are removed.

## Notes
- The area polyline that count mode drew is removed, unless a count field still uses it. A polyline you picked as the area is kept.
- The **Close** button on the count toolbar does the same.
- The Count palette stays open. Close it with [`COUNTLISTCLOSE`](COUNTLISTCLOSE-Command).
