---
summary: Creates a gravity pipe network with a structure at each point you specify and pipes between them.
related: CREATEPRESSURENETWORK, CREATEPOINTS
---

## Usage
1. Specify structure locations; press Enter after the last.
2. Press Enter, or first set options: **Structure family**, **Pipe family**.

## Notes
- Each pipe runs from one structure to the next and is connected to both.
- At an option's prompt, type part of a family's name (for example `PVC`) to pick it, or `?` to list the families.
- The families are those of the default parts list. Without a choice, structures are null structures and pipes corrugated metal pipes.
- The network is named Network and a number.
