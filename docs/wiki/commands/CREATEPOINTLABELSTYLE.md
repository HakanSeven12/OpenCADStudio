---
summary: Creates a point label style and gives it to COGO points.
related: CREATEPOINTS, CREATEPOINTGROUP
---

## Usage
1. Select COGO points to give the style, or press Enter for none.
2. Press Enter, or first set options:
   - **Text height**: the height of the label's texts.
   - **Color**: the color number (1-255) of the label's texts.
   - **Orientation**: whether the label turns with the object, the view or the world.

## Notes
- The style is a copy of the drawing's default point label style with the settings given; settings not given keep the default style's.
- It is named Point Label Style and the first free number.
