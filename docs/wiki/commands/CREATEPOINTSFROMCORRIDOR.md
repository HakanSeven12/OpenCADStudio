---
summary: Creates COGO points at the corridor's stations for the point codes you choose, in a new point group.
related: CREATECORRIDOR, CREATEPOINTGROUP
---

## Usage
1. Run the command. With several corridors, select one.
2. In the window, choose the entire corridor range or a baseline with start and end stations, the point group name and the point codes.
3. Press **OK**.

## Notes
- Each point is described by its code and placed on the point creation layer.
- A station shared by two runs of a code gives one point.
- The command is one undo step.
