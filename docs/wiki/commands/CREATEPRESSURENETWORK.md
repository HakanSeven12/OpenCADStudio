## Usage
1. Specify at least two pipe vertices; press Enter after the last.
2. Press Enter, or first set **Pipe size**.

## Notes
- Each pipe runs from one vertex to the next, joined to the pipe before it.
- At the **Pipe size** prompt, type part of a pipe's description (for example `8 in`) to pick it, or `?` to list the pipes of the default catalog. Without a choice, pipes are the catalog's first.
- The network is named Pressure Network and a number.
