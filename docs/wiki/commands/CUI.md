## Usage
1. Run `CUI`. The Customize User Interface dialog opens.
2. Click **New panel**, or pick a panel in the **Panels** list.
3. Type a **Title** for the panel.
4. Type a command or alias in the box and click **Add**, or press Enter.
5. Click **Close** when done.

## Dialog
| Control | What it does |
|---|---|
| **Panels** list | Your own panels. They show on the My Tools tab of the ribbon. |
| ↑ / ↓ / × next to the panels | Move the selected panel up or down, or delete it. |
| **Commands** list | The commands of the selected panel. Use ↑, ↓ and × on a row to reorder or remove it. |
| **Keyboard Shortcuts…** | Opens the keyboard shortcut editor. |

## Notes
- Every change shows on the ribbon at once.
- You can run this command without an open drawing.
