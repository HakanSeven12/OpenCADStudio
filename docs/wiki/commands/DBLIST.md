## Usage
1. Start the command. No selection is needed.

For each object the command line shows its type, handle, layer, color and linetype, followed by details such as coordinates when available. The last line gives the number of objects.

## Notes
- Use [`LIST`](LIST-Command) to list only selected objects.
- In a large drawing the list can be very long.
