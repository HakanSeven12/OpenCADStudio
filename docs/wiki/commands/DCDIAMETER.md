## Usage
1. Select an arc or circle.
2. Specify the dimension line location.
3. Enter the value, or a name and value such as `dia1=20`. Press Enter to keep the measured value shown in brackets.

The arc or circle changes to match the value you enter.

## Notes
- The value can be a number, an expression, or the name of an existing parameter.
- The new constraint uses the current constraint form, dynamic or annotational. Change it with [`DCFORM`](DCFORM-Command) or [`CCONSTRAINTFORM`](CCONSTRAINTFORM-System-Variable).
