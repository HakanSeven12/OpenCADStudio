## Usage
1. Select the objects first, or start the command and select them at the prompt.
2. Enter an option [Show/Hide] <Show>.

The command line reports how many constraint indicators were updated.

## Options
| Option | What it does |
|---|---|
| **Show** (`S`) | Shows the dimensional constraints of the selected objects. |
| **Hide** (`H`) | Hides the dimensional constraints of the selected objects. |
