---
summary: Edits the text of a single-line text, multiline text, attribute, dimension or leader in place.
related: TEXTEDIT, MTEXT, TEXT, DIMTEDIT
---

## Usage
1. Select one text object first, or start the command and select it at the prompt.
2. Edit the text in the editor that opens.

## Notes
- Single-line text, attributes, dimension text overrides and tolerances open a plain text box.
- Multiline text and multileaders open the multiline text editor.
- Picking a leader edits the text it annotates.
- If the one selected object has no text, the command reports that it is not text.
