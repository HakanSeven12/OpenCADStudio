## Usage
1. The command line shows the current constraint form (annotational or dynamic).
2. Type an option, or press Enter to use the type you chose last time.
3. Follow the prompts of the command that starts.

## Options
| Option | What it does |
|---|---|
| **Linear** (`L`) | Runs [`DCLINEAR`](DCLINEAR-Command). |
| **Horizontal** (`H`) | Runs [`DCHORIZONTAL`](DCHORIZONTAL-Command). |
| **Vertical** (`V`) | Runs [`DCVERTICAL`](DCVERTICAL-Command). |
| **Aligned** (`A`) | Runs [`DCALIGNED`](DCALIGNED-Command). |
| **ANgular** (`AN`) | Runs [`DCANGULAR`](DCANGULAR-Command). |
| **Radius** (`R`) | Runs [`DCRADIUS`](DCRADIUS-Command). |
| **Diameter** (`D`) | Runs [`DCDIAMETER`](DCDIAMETER-Command). |
| **Form** (`F`) | Runs [`DCFORM`](DCFORM-Command) to choose between annotational and dynamic constraints. |
| **Convert** (`C`) | Runs [`DCCONVERT`](DCCONVERT-Command) to turn existing dimensions into dimensional constraints. |
