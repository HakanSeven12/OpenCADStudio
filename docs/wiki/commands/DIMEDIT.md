## Usage
1. Choose the type of editing, or press Enter for **Home**.
2. Answer the prompt of that option.
3. Select the dimensions to edit and press Enter. The command line reports how many were updated.

## Options
| Option | What it does |
|---|---|
| **Home** (`H`) | Moves the dimension text back to its default position and resets its rotation. |
| **New** (`N`) | Replaces the dimension text with what you type. Press Enter or type `<>` to show the measured value again. |
| **Rotate** (`R`) | Rotates the dimension text to the angle you type, in degrees. |
| **Oblique** (`O`) | Select the dimensions first, then type the obliquing angle of the extension lines, between -85 and 85 degrees. Press Enter for no slant. |

## Notes
- Oblique only changes linear and aligned dimensions.
- Dimensions on locked layers are not changed.
- The **Oblique** button in the slide-out of the Dimensions panel runs this command with the Oblique option.
