## Usage
1. Run `DSETTINGS`. The Drafting Settings dialog opens on the **Snap and Grid** tab.
2. Change settings on the tabs: **Snap and Grid**, **Polar Tracking**, **Object Snap**, **3D Object Snap**, **Dynamic Input**, **Quick Properties** and **Selection Cycling**.
3. Click **OK** to save and close, **Apply** to save and keep the dialog open, or **Close** to leave.

## Notes
- If you close the dialog with unsaved changes, it asks whether to discard them.
- Running `DSETTINGS` while the dialog is open closes it.
- [`OSNAP`](OSNAP-Command) opens the same dialog on the **Object Snap** tab.
