---
summary: Creates a polygon mesh between four edges that meet end to end.
related: REVSURF, RULESURF, TABSURF, SURFTAB1
---

## Usage
1. Select the four edges one after another.

## Notes
- The first edge runs the mesh's M direction ([`SURFTAB1`](SURFTAB1-System-Variable) divisions); the two edges touching it run the N direction ([`SURFTAB2`](SURFTAB2-System-Variable) divisions).
