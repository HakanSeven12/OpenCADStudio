## Usage
1. Select exactly two objects, or start the command and select them at the `Select objects:` prompt.
2. The first object is the reference. The second one moves to line up with it.
3. The constraint is applied.

## Notes
- If you select anything other than exactly two objects, you see `Select exactly two entities (first = reference, second = the one that moves), then run this constraint again.`
- [`LCONSTRAINT`](LCONSTRAINT-Command) does the same thing.
