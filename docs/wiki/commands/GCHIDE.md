## Usage
1. Select objects, then press Enter. If objects are already selected, this step is skipped.

The command line reports how many constraint indicators were updated.

## Notes
- Only geometric constraints are affected. Use [`DCHIDE`](DCHIDE-Command) for dimensional constraints.
- The constraints stay in the drawing and keep working; only their bars are hidden.
