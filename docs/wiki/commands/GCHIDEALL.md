---

## Usage
Run the command. It needs no input and reports how many constraint indicators were updated.

## Notes
- Only geometric constraints are affected. Use [`DCHIDEALL`](DCHIDEALL-Command) for dimensional constraints.
- The constraints keep working; only their bars are hidden.
