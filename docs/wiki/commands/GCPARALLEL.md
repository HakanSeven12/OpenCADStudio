## Usage
1. Select objects: pick exactly two objects, then press Enter. The first one you pick is the reference; the second one turns to match it.

If two objects are already selected when you start the command, the constraint is applied at once.

## Notes
- You must select exactly two objects. Any other count is refused with a message.
- Both objects must lie on the same plane.
- When both objects are lines, the second line turns about its own start point and keeps its length.
