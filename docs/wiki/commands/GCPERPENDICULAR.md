## Usage
1. Select first object: pick a line segment, polyline segment, text, MText, or the major or minor axis of an ellipse or elliptical arc.
2. Select second object: pick another supported object.

## Notes
- On an ellipse, the axis nearer to where you click is used.
- You can select exactly two supported objects first and then start the command; the constraint is applied at once. Any other count is refused.
- Both objects must lie on the same plane.
