## Usage
1. Select the objects first.
2. Run the command. The geometric constraint bars on those objects are shown again, and the command line reports how many were reset.

## Notes
- The command does not ask for objects. If nothing is selected, it reports "No objects selected."
- If the selected objects have no geometric constraints, it says so.
- Dimensional constraints are not affected.
