## Usage
Run the command. It needs no input. Each run shows or hides the palette.

## Notes
- The palette works on the selected objects. Besides line attributes such as transparency and lineweight, it can give closed objects a hatch or one-color or two-color gradient fill, and edit that fill.
- It also offers **Set all attributes ByLayer**, **Set all attributes ByBlock**, **Remove ByLayer / ByBlock**, **Create Layer with active settings** and **Create fills on the current layer**.
- Objects on locked layers are not changed.
