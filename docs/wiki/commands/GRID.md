---
summary: Turns the reference grid on or off in the drawing area.
related: SNAP, DSETTINGS, ORTHO, POLAR
---

## Usage
Run the command. It needs no input. Each run switches the grid between shown and hidden.

## Notes
- The **Grid** button on the status bar does the same.
- You can use it during another command (`'GRID`) without ending that command.
- [`GRIDMODE`](GRIDMODE-System-Variable) holds whether the grid is shown, and [`GRIDUNIT`](GRIDUNIT-System-Variable) sets the grid spacing.
