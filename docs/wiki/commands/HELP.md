## Usage
- Run `HELP` with no command active to open the wiki home page.
- Press F1, or type `'HELP`, while a command is running to open that command's page. The running command is not ended.
- Type `HELP <name>` to open the page of a command, alias or system variable. For example, `HELP L` opens the [`LINE`](LINE-Command) page.

## Notes
- If the name is not a known command, alias or system variable, the wiki is searched for it.
- The command line shows the address that is opened.
- `HELP` also works from the Start tab.
