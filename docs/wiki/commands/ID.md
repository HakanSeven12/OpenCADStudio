---
summary: Shows the X, Y and Z coordinates of a point you pick.
related: DIST, LIST
---
## Usage
1. Specify a point (you can use object snaps).
2. The command line shows `X = …,  Y = …,  Z = …` for that point.

## Notes
- The coordinates are given in the current UCS.
- Values are formatted with the drawing's current length units.
- Press Enter or Esc to leave without picking a point.
