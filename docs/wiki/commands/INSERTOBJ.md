## Usage
1. On Windows, the system Insert Object window opens; choose the file there. On other systems, and in the web app, a file window opens instead.
2. Specify the insertion point (the lower-left corner of the picture).
3. Specify the width: move the cursor to the right and click. The height follows the picture's proportions. Or press Enter to use a default width of one drawing unit per 100 pixels.

## Notes
- Only a picture from a file can be embedded. Choosing a file that is not a supported image shows a message.
- The picture is stored inside the drawing, so the drawing file travels alone.
