## Usage
1. Select the text objects, or run the command and select them at `Select objects:`. Only single-line text and multiline text are taken.
2. At `Enter a justification option [Left/Align/Fit/Center/Middle/Right/TL/TC/TR/ML/MC/MR/BL/BC/BR] <Left>:`, type an option, or press Enter for the default.
3. The justification changes and the text stays where it was.

## Options
| Option | What it does |
|---|---|
| **Left**, **Center**, **Right** | Baseline left, centre or right. |
| **Align**, **Fit** | The baseline from its start to its end. |
| **Middle** | The middle of the text. |
| **TL**, **TC**, **TR** | Top left, top centre, top right. |
| **ML**, **MC**, **MR** | Middle left, middle centre, middle right. |
| **BL**, **BC**, **BR** | Bottom left, bottom centre, bottom right. |

## Notes
- The default is the option you used last.
- Multiline text has no baseline options: **Left**, **Align** and **Fit** use bottom left, **Center** bottom centre, **Right** bottom right, and **Middle** middle centre.
- The change can be undone.
