## Usage
1. Select the objects, or run the command and select them at the prompt.
2. Press Enter. The objects move to the current layer and the command line reports how many changed.

## Notes
- Objects on locked layers are not changed.
- Properties set to ByLayer (colour, linetype, lineweight) take the current layer's values at once.
- The change can be undone.
