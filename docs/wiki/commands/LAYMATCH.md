## Usage
1. At `Select objects to change layer:`, pick the objects to move and press Enter. If objects are already selected, this step is skipped.
2. At `Select source object to match layer from:`, pick an object on the layer you want.
3. The selected objects move to that object's layer.

## Notes
- To move objects to the current layer instead, use [`LAYCUR`](LAYCUR-Command).
- To put copies on another layer and keep the originals, use [`COPYTOLAYER`](COPYTOLAYER-Command).
- `LAYMCH` runs the same command.
