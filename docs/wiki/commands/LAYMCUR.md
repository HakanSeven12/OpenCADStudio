## Usage
1. Select an object. If objects are already selected, the layer of the first one becomes current at once.
2. Otherwise, at the `Select objects:` prompt, pick one object. The command finishes on the first pick.
3. The command line reports the new current layer.

## Notes
- New objects are drawn on the current layer.
