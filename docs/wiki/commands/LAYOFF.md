## Usage
1. If objects are already selected, their layers are turned off at once.
2. Otherwise, at `Select an object on the layer to be turned off or [Undo]:`, pick an object. Its layer is turned off right away.
3. Pick more objects, or press Enter or Esc to finish.

## Options
| Option | What it does |
|---|---|
| **Undo** (`U`) | Turns the last layer you turned off back on. |

## Notes
- Layer `0` is not turned off when you use a preselection.
- To turn every layer back on, use [`LAYON`](LAYON-Command).
- Each layer turned off is one undo step.
