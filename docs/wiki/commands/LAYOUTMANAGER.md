## Usage
1. Run `LAYOUTMANAGER`.
2. The Layout Manager lists Model Space and every paper space layout, with its status (Active or Inactive).
3. Select a layout and use the buttons:
   - **New Layout** adds a layout.
   - **Rename** gives the selected layout the name typed in the **Name** box.
   - **Delete** removes the selected layout.
   - **Set Current** switches to the selected layout.
   - **Move Left** and **Move Right** change the order of the layout tabs.
4. Click **OK** to close the dialog.

## Notes
- The command works only in an open drawing, not on the Start tab.
- `LAYOUTPANEL` opens the same dialog.
- For a command-line version that suits scripts, use `-LAYOUT`.
