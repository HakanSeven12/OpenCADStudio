related: ID, DIST, AREA, PROPERTIES, DBLIST
---

## Usage
1. Select objects. If objects are already selected, they are listed at once.
2. Otherwise, at the `Select objects:` prompt, pick the objects and press Enter.
3. The command line shows one entry per object.

## Notes
- Each entry shows the object type, its handle, layer, color and linetype.
- For many object types, a second line shows geometry, for example the start, end and length of a line, or the center, radius and area of a circle.
