## Usage
1. Specify the vertex point, or type `LINES`.
2. Specify the first ray point.
3. Specify the second ray point. The angle is shown in degrees, and the command ends.

## Options
| Option | What it does |
|---|---|
| **Lines** (`LINES`) | Select the first line, then the second line. Shows the smaller angle between them. |
| **Points** (`POINTS`) | At the first-line prompt, goes back to picking a vertex and two points. |

## Notes
- This is the Angle option of [`MEASUREGEOM`](MEASUREGEOM-Command) as a single command.
