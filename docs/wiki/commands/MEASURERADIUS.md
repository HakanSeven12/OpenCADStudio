## Usage
1. Select an arc, circle or circular region edge.
2. The command line shows `Radius = ..., Diameter = ...`, and the command ends.

## Notes
- This is the Radius option of [`MEASUREGEOM`](MEASUREGEOM-Command) as a single command.
