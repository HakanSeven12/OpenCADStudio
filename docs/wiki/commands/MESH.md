## Usage
1. Choose the primitive: Box, Cone, CYlinder, Pyramid, Sphere, Wedge or Torus (Enter repeats the last one).
2. Specify its size with the same prompts as the solid of that shape.

## Options
- **SEttings**: the smoothness level (0 to 4) new mesh primitives get.

## Notes
- The divisions of each primitive come from [`MESHPRIMITIVEOPTIONS`](MESHPRIMITIVEOPTIONS-Command) (the `DIVMESH...` system variables).
- On the Mesh tab the Primitives drop-down starts each primitive directly.
