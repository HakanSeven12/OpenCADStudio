---
summary: Inserts a block as a rectangular array of rows and columns held in one block reference.
related: INSERT, ARRAY, BLOCK
---

## Usage
1. Enter the block name. Start typing to filter the list of blocks; matching names appear as options you can click.
2. Specify the insertion point.
3. Enter the number of rows (default 1).
4. Enter the number of columns (default 1).
5. Enter the row spacing (default 0).
6. Enter the column spacing (default 0). The array is created.

## Notes
- Press Enter at any number prompt to keep the value shown in angle brackets.
- The drawing must contain at least one user-defined block, or the command shows an error and ends.
- Rows and columns are at least 1. The whole array is one object.
- The blocks you use most often and most recently are listed first.
