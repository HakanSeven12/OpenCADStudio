---
summary: Adds leader lines to, or removes leader lines from, an existing multileader.
related: MLEADER, AIMLEADEREDITADD, AIMLEADEREDITREMOVE, MLEADERALIGN
---

## Usage
1. Select a multileader. If exactly one multileader is selected when you start, it is used.
2. Specify a leader arrowhead location for each new leader line, or type `R` to switch to removing.
3. When removing, click the leader lines to take out.
4. Press Enter to apply the changes.

## Options
| Option | What it does |
|---|---|
| **Remove leaders** (`R`) | Switches to removing: click leader lines to remove them. |
| **Add leaders** (`A`) | Switches back to adding new leader lines. |

## Notes
- Changes are applied only when you press Enter. Press Enter with no changes to end without editing.
- If you remove every leader line, the content stays on its own and a message tells you no leaders are left.
- The ribbon's Add Leader and Remove Leader tools start this command directly in add or remove mode.
