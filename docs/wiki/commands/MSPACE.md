---
summary: Switches from paper space to model space through a layout viewport.
related: PSPACE, MVIEW, CHSPACE
---

## Usage
1. On a layout tab, type `MSPACE`.
2. The first viewport of the layout becomes active, and you work in model space inside it.

## Notes
- The command works only on a layout tab. On the Model tab it shows an error.
- If a viewport is already active, nothing changes.
- If the layout has no viewport, an error tells you so. Create one with [`MVIEW`](MVIEW-Command).
- Use [`PSPACE`](PSPACE-Command) to go back to paper space.
