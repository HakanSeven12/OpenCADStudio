---
summary: Repeats the next command you start until you cancel it.
related: OOPS, UNDO
---

## Usage
1. Run the command (alias `MUL`).
2. At `Enter command name to repeat:` type a command name, for example `CIRCLE`.
3. Each time the command finishes it starts again. Press Escape to stop.

## Notes
- Only commands that ask for input repeat; a command that finishes at once runs one time.
