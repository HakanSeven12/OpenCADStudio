## Usage
1. Specify point. A point object is placed.
2. Keep picking or typing points; each one adds another point object.
3. Press Enter (Done) or Esc to finish.

## Notes
- [`POINT`](POINT-Command) places a single point and ends.
- How points look is set with [`DDPTYPE`](DDPTYPE-Command) and the `PDMODE` and `PDSIZE` system variables.
