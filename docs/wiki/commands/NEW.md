## Usage
1. Run the command. A file dialog opens in the folder of the default template.
2. Pick a template file (DWT, DWG or DXF).
3. A new drawing tab opens with the layers, styles and other settings of the template.

## Notes
- Cancel the dialog to do nothing.
- [`QNEW`](QNEW-Command) skips the dialog and uses the default template set in Options › Files.
