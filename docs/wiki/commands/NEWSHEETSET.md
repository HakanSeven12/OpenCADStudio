## Usage
1. **Begin**: choose **An empty sheet set** or **Existing drawings**.
2. **Details**: enter the name of the new sheet set, an optional description and the folder where the .dst file is stored. You can create a folder hierarchy based on subsets and open **Sheet Set Properties...**.
3. **Choose Layouts** (only for Existing drawings): add folders that contain drawings, and tick the layouts to import as sheets.
4. **Confirm**: check the summary and click **Finish**.

## Notes
- Use **Back** and **Next** to move between steps, or click a step at the top.
- The default name is "New Sheet Set (n)" in your Documents folder.
