---
summary: Adds a normal constraint that keeps a line at right angles to a circle or arc, so the line passes through its center.
related: QCONSTRAINT, PCONSTRAINT, DELCONSTRAINT, PARAMETERS
---

## Usage
1. Select exactly two objects: first the reference, then the one that moves.
2. Run the command. If nothing is selected, the command asks you to select the objects first.
3. The constraint is added and the second object moves to satisfy it.

## Notes
- If you select more or fewer than two objects, the selection is cleared and a message asks you to select exactly two.
