---
summary: Adds a point-on-curve constraint that keeps a point of one object on another object.
related: CPCONSTRAINT, MPCONSTRAINT, DELCONSTRAINT
---

## Usage
1. Select exactly one object: the line or circle the point should stay on.
2. Run the command. If nothing is selected, it asks you to select the object first.
3. Specify point. Pick the point on another object, such as a line end point.
4. The constraint is added and the point moves onto the selected object.

## Notes
- If you select more than one object, the selection is cleared and a message asks you to select exactly one.
