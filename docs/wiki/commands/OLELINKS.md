summary: Lists the linked OLE objects in the drawing and their source applications on the command line.
related: INSERTOBJ, OLEHIDE
---

## Usage
1. Run the command. Each linked OLE object is listed with a number and its source application.

## Notes
- The command only lists links. It does not update, change or break them.
- Embedded (not linked) OLE objects are not listed. When there are no links, nothing is printed.
