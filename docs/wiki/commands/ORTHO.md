---
summary: Turns Ortho mode on or off, so the cursor moves only horizontally or vertically.
related: POLAR, DSETTINGS
---

## Usage
1. Run the command. Ortho mode turns on if it was off, or off if it was on.

## Notes
- Turning Ortho on turns Polar tracking off.
- This is the same switch as the Ortho button on the status bar.
- If you switch Ortho during a command that turned it off for its own use, your choice stays after the command ends.
