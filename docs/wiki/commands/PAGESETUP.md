## Usage
1. Switch to the layout or model space you want to set up.
2. Run the command. The plot dialog opens with the settings stored for that layout.
3. Change the settings you need.

## Notes
- Page setup and plotting share one dialog; [`PLOT`](PLOT-Command) opens the same dialog.
- In model space the Layout plot area is not offered; Window is used instead.
- `-PAGESETUP` manages named page setups on the command line (SAVE, APPLY, RENAME, LIST, DELETE).
