## Usage
1. Run the command.
2. Drag with the left mouse button to move the view.
3. Press Esc to exit.

## Notes
- PAN can run transparently while another command is active: type `'PAN`.
- This is the way to pan without a middle mouse button, for example on a trackpad or in the web app.
