## Usage
1. Copy or cut objects with [`COPYCLIP`](COPYCLIP-Command) or [`CUTCLIP`](CUTCLIP-Command).
2. Switch to the drawing or space you want to paste into.
3. Start `PASTEORIG`. The objects are pasted at once, with no point to pick.

## Notes
- The command line reports how many objects were pasted.
- If the clipboard is empty, an error is shown and nothing changes.
- You can undo the paste.
