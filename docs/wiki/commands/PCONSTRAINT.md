## Usage
1. Select the two objects, in order: first the reference object, then the object that moves.
2. Press Enter to finish the selection.

The second object is turned to lie parallel to the first, and the constraint is kept.

## Notes
- If you select the objects before starting the command, the constraint is added at once.
- Exactly two objects are needed. With any other number, an error asks you to select two and run the command again.
