## Usage
1. Select the PDF underlay. You can select more than one.
2. Enter an option, **Fade**, **Contrast** or **Monochrome**.
3. For **Fade** or **Contrast**, enter a value from 0 to 100. For **Monochrome**, answer **Yes** or **No**.

## Options
| Option | What it does |
|---|---|
| **Fade** (`F`) | How faded the underlay is drawn, 0 to 100. |
| **Contrast** (`C`) | The underlay's contrast, 0 to 100. |
| **Monochrome** (`M`) | Draws the underlay in black and white (**Yes**) or in its own colours (**No**). |

## Notes
- The option and the values offered as defaults are the last ones you used in the session.
- The change applies to every selected underlay as one undo step.
- [`ADJUST`](ADJUST-Command) does the same for raster images and other underlay types.
