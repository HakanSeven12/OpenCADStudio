---
summary: Turns the performance panel on or off.
---

## Usage
1. Type `PERF`. The performance panel opens, or closes if it is already open.

## Notes
- The panel shows a running log of how long drawing and interaction take, and a summary of the last geometry update (time, number of wires).
- Use **Copy** to copy the log, for example into a bug report, and **Clear** to empty it.
