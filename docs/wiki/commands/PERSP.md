## Usage
1. Type `PERSP`. The view changes to perspective projection, and the command line confirms it.

## Notes
- `PERSP` always switches to perspective; it does not toggle. To go back to parallel projection, use the **Ortho** button in the same ribbon panel, or set [`PERSPECTIVE`](PERSPECTIVE-Command) to 0.
- The view is adjusted so that what you see stays framed the same way.
