---
summary: Sets whether the current view uses perspective (1) or parallel (0) projection.
related: PERSP, 3DORBIT, VIEW
---

## Usage
1. Type `PERSPECTIVE`.
2. Enter the new value. The prompt shows the current value.
   - `0` switches to parallel projection.
   - `1` switches to perspective projection.

You can also type the value right after the name, for example `PERSPECTIVE 1`.

## Notes
- Any value other than 0 or 1 is rejected.
