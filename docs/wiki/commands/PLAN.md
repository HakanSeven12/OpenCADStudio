---
summary: Shows the plan (top) view of the current UCS, a named UCS, or the world coordinate system.
related: UCS, VIEW, 3DORBIT
---

## Usage
1. Type `PLAN`.
2. Choose which plan view to show, or press Enter for **Current ucs**.
3. For **Ucs**, type the name of a saved UCS.

## Options
| Option | What it does |
|---|---|
| **Current ucs** (`C`) | Looks straight down on the XY plane of the current UCS. |
| **Ucs** (`U`) | Looks straight down on the XY plane of a saved UCS you name. |
| **World** (`W`) | Looks straight down on the world XY plane. |

## Notes
- You can type the option with the command, for example `PLAN WORLD` or `PLAN UCS Front`.
- If the named UCS does not exist, an error is shown.
- When you work inside a layout viewport, the command changes the view of that viewport.
