summary: Sets the plot area to a window you pick in the drawing and opens the Plot dialog.
related: PLOT, PAGESETUP, PRINTALL
---

## Usage
1. Specify the first corner of the plot window.
2. Specify the opposite corner.

The plot area is set to **Window** with the picked rectangle, and the Plot dialog opens.

## Notes
- The window is remembered and used by the next plot.
- In a layout, the corners are taken in paper space. When you work inside a viewport, the points are converted from model space to the layout.
- Ortho and polar tracking do not restrict the corners.
- Press Enter to cancel.
