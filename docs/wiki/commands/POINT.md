## Usage
1. Specify a point. You can click, snap to geometry, or type coordinates.

The point is created and the command ends. To place several points in one go, use [`MULTIPOINT`](MULTIPOINT-Command).

## Notes
- How points look (the marker shape and its size) is set with [`DDPTYPE`](DDPTYPE-Command) or the `PDMODE` and `PDSIZE` variables.
