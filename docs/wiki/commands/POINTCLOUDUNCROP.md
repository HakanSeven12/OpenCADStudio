---
summary: Removes all crops from a point cloud.
related: POINTCLOUDCROP, POINTCLOUDMANAGER
---

## Usage
1. `Select point cloud:` pick a point cloud.

All crops of that cloud are removed and all its points are shown again.

## Notes
- To remove only the newest crop, use the **Remove last** option of [`POINTCLOUDCROP`](POINTCLOUDCROP-Command).
- With only point clouds selected, the **Remove All Cropping** button on the toolbar at the right edge of the drawing area does the same for the selection.
