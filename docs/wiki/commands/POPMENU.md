## Usage
1. Right-click in the drawing with nothing running and choose **Customize** to add the commands you want.
2. Bind POPMENU to a key in the shortcut editor, or type it.
3. The menu opens at the cursor with only your commands. Pick one to run it; Esc or a click elsewhere closes the menu.

## Notes
- The menu lists the same commands and separators you added to the right-click menu, in the same order.
