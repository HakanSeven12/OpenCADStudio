## Usage
1. Run the command. The dialog lists every paper layout of the drawing, all ticked.
2. Untick the layouts you do not want. **Select all** and **Select none** help.
3. Optionally click **Options…** to set plot settings for the whole batch.
4. Click **PDF** to save one multi-page PDF, or **Print** to send the layouts to the printer.

## Notes
- Each layout is output with its own page setup, unless you set shared settings with **Options…**.
- The Model tab is not listed.
- The dialog shows the printer that will be used.
- The result, or any error, is reported on the command line.
