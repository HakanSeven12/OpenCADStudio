---
summary: Shows or hides the Properties palette, where you view and change the properties of the selected objects.
related: QUICKPROPERTIES, MATCHPROP, PROPS
ribbon: View tab › Palettes panel
---

Run `PROPERTIES` to open the Properties palette. Run it again to close it.

## Notes
- If the palette is open but tucked away (for example on an auto-hiding edge, or behind another palette in the same group), the command brings it into view instead of closing it.
- Select objects to see and edit their properties in the palette.
