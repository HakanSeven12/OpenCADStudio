---
summary: Leaves the active layout viewport and returns to paper space on the layout sheet.
related: MSPACE, MVIEW, CHSPACE
---

Run `PSPACE` while you work inside a viewport on a layout tab. The viewport is no longer active and you edit the sheet again.

## Notes
- Clicking the MODEL button on the status bar while a viewport is active does the same.
- A command that is running inside the viewport is cancelled.
- The selection is cleared, and grid and snap return to the sheet's own settings.
- To go back into a viewport, use [`MSPACE`](MSPACE-Command).
