summary: Opens a new drawing tab from the default template, without asking for a template.
related: NEW, OPEN, QSAVE
---

## Usage
1. Run the command. A new drawing opens in a new tab.

## Notes
- The default template is set in **Options › Files › Default template for new drawings**. When it is empty, the new drawing is blank.
- If the template cannot be loaded, an error is shown and you get a blank drawing.
- The new drawing keeps the current Ortho and running object snap settings.
- To choose a template each time, use [`NEW`](NEW-Command).
