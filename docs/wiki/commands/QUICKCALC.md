## Usage
1. Run the command. The **QuickCalc** panel opens. Run it again to close the panel.
2. Type an expression, for example `2*300 + 90`, and press Enter. The result is added to the history.

## Options
| Option | What it does |
|---|---|
| Point, distance and angle tools | Pick a point, the distance between two points, or an angle in the drawing and put the value into the input. |
| Clear history | Removes the history list. |
| Copy | Copies the result. |
| Send | Pastes the result to the command line. |
| Standard / Scientific | Switches the keypad between basic keys and scientific functions. |
| **DEG** / **RAD** | Switches the angle unit used by trigonometric functions between degrees and radians. |
| **Units** | Converts a value between units of length, area or angle. **Swap units** swaps the two units; **Insert** puts the converted value into the input. |
| **Variables** | Stores constants and functions in categories. Double-click one to insert it. Typing `$name = value` also adds a constant. |

## Notes
- Start an expression with `*` to reuse the last answer (`ans`).
- Click a history line to load it into the input again.
- The panel can be docked or float as its own window.
- Typed with an expression on the same line, for example `QUICKCALC (2+3)*4`, the command shows the result on the command line without opening the panel.
