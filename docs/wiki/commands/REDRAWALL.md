---
summary: Refreshes the display of every viewport without changing the drawing.
related: REDRAW, REGEN
---

## Usage
1. Run the command. There are no prompts.

## Notes
- All viewports are redrawn. Use [`REDRAW`](REDRAW-Command) to redraw only the current one.
- The drawing data is not touched and no undo step is recorded.
- The command line shows "REDRAWALL: viewports refreshed."
