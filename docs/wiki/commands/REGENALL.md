---
summary: Regenerates the drawing; currently does the same as `REGEN`.
related: REGEN, REDRAWALL
---

`REGENALL` runs the same regeneration as [`REGEN`](REGEN-Command): the display geometry of the whole drawing is rebuilt from the drawing data, and fields set to update on regeneration are updated.

## Notes
- The command line shows "REGEN: regenerated model."
- The drawing itself is not changed and no undo step is recorded.
