## Usage
1. Type `REPORT`. The command line shows "Opening feedback page...".
2. Your web browser opens a new issue form. The text already lists the program version, revision, build and platform.
3. Describe the problem and the steps to reproduce it above those lines, then submit the form in the browser.

## Notes
- The **Send Feedback** button on the start page runs the same command.
- Nothing in the drawing changes. You need a web browser and an account on the issue tracker to submit the report.
