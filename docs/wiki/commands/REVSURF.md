---
summary: Creates a polygon mesh by revolving a curve about an axis.
related: RULESURF, TABSURF, EDGESURF, SURFTAB1
---

## Usage
1. Select the curve to revolve.
2. Select the line or open polyline that defines the axis. The axis points from the end nearer the pick to the other end.
3. Specify the start angle and the included angle (positive is counter-clockwise).

## Notes
- [`SURFTAB1`](SURFTAB1-System-Variable) sets the divisions around the axis, [`SURFTAB2`](SURFTAB2-System-Variable) those along the curve.
