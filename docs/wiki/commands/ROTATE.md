## Usage
1. Select the objects, or start the command and select them at the prompt.
2. Specify the rotation center.
3. Specify the rotation angle: type a value or pick a point. A preview follows the cursor. Press Enter to use the angle shown in the prompt.

## Options
| Option | What it does |
|---|---|
| **Copy** (`C`) | Rotates a copy and leaves the original objects in place. |
| **Reference** (`R`) | Rotates from a reference angle to a new angle. Pick two points or type the reference angle, then pick or type the new absolute angle. The objects turn by the difference. |

## Notes
- Angles are measured in the current UCS.
- The last angle you used is offered as the default the next time.
