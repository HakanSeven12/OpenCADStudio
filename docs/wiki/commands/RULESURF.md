---
summary: Creates a polygon mesh of straight lines between two curves.
related: REVSURF, TABSURF, EDGESURF, SURFTAB1
---

## Usage
1. Select the first curve.
2. Select the second curve.

## Notes
- Both curves must be open or both closed. An open curve runs from its end nearer the pick, so picking opposite ends twists the mesh.
- [`SURFTAB1`](SURFTAB1-System-Variable) sets the number of rulings.
