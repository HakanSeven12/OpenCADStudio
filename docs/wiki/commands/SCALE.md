## Usage
1. Select the objects, or start the command and select them at the prompt.
2. Specify the base point.
3. Specify the scale factor: type a value, or move the cursor and click (the distance from the base point is the factor). Press Enter to use the factor shown in the prompt.

## Options
| Option | What it does |
|---|---|
| **Copy** (`C`) | Scales a copy and leaves the original objects in place. |
| **Reference** (`R`) | Scales by new length divided by reference length. Pick two points or type the reference length, then pick or type the new length from the base point. |

## Notes
- The objects are scaled equally in every direction.
- The last factor you used is offered as the default the next time.
