---
summary: Prints a report of the current selection: the space, a count by object type and by block, and the list of object handles.
related: SELH, LIST, SELECTALL
---

## Usage
1. Select the objects first.
2. Type `SELHANDLES`.
3. The command line shows how many objects are selected and in which space (model space or the named paper layout), a count for each object type and each block name, and the hexadecimal handles of all selected objects, separated by commas.

## Notes
- If nothing is selected, an error asks you to select objects first.
- The handle list helps you compare what is on screen with the objects stored in the file.
