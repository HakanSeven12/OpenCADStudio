summary: Reads or changes the value of a system variable from the command line.

---

## Usage
1. Enter the variable name.
2. Enter the new value, or press Enter to only show the current value.

## Command-line form
You can give both on one line, for example `SETVAR LTSCALE 2`. Use `SETVAR ?` to list the variables that SETVAR knows.

## Notes
- Some variables are read-only, for example `CLAYER`, `CELTYPE` and `TEXTSTYLE` in the list.
- Many variables can also be typed directly at the command prompt without SETVAR.
