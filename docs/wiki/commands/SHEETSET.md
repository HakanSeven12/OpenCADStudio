## Usage
1. Start the command. The Sheet Set Manager opens.
2. Open a sheet set, or create a new one.
3. Right-click a sheet set, subset or sheet to add new sheets and subsets, import layouts as sheets, rename and renumber, remove items, or edit properties.

## Notes
- Use [`SHEETSETHIDE`](SHEETSETHIDE-Command) to close the palette. The ribbon button turns the palette on and off.
- Use [`NEWSHEETSET`](NEWSHEETSET-Command) to start the new sheet set wizard and [`OPENSHEETSET`](OPENSHEETSET-Command) to open an existing sheet set file.
