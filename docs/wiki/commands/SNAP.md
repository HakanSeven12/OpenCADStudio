---
summary: Turns snapping the cursor to the grid on or off.
related: GRID, DSETTINGS, ISODRAFT, ISOPLANE
---

`SNAP` switches grid snap on or off each time you run it. When it is on, the cursor jumps to the snap grid points. The status bar **Snap** button shows and changes the same setting.

## Notes
- The command has no prompts. Set the snap spacing in [`DSETTINGS`](DSETTINGS-Command).
