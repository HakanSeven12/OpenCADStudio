## Usage
1. Enter a solid editing option: type `B` for **Body**.
2. Enter a body editing option: type `S` for **Shell**.
3. Continue as in [`SHELL`](SHELL-Command): select a solid, pick faces to remove, then enter the offset distance.

## Options
| Option | What it does |
|---|---|
| **Body** (`B`) | Goes to the body editing options. |
| **Shell** (`S`) | Hollows the solid, the same as [`SHELL`](SHELL-Command). |
| **eXit** (`X`) | Ends the command. |

## Notes
- Face and edge editing options are not available. If you selected one solid before you start the command, the solid selection is skipped.
