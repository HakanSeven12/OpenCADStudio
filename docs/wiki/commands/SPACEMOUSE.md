`SPACEMOUSE` opens [`OPTIONS`](OPTIONS-Command) on the User Preferences page. There you turn 3D mouse input on or off, choose the navigation mode, set the pan speed, and reverse the pan direction.

## Notes
- 3D mouse input works only in the Windows desktop app, with the device driver installed.
