`SPACEMOUSE3D` sets the 3D mouse navigation mode to **3D navigation**. You can pan, zoom and orbit model views. On paper sheets rotation stays locked.

## Notes
- 3D mouse input works only in the Windows desktop app. You can also pick the mode in [`SPACEMOUSE`](SPACEMOUSE-Command).
