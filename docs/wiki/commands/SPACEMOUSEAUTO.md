`SPACEMOUSEAUTO` sets the 3D mouse navigation mode to **Follow context**. On paper sheets you can pan and zoom. In model views you can also orbit. This is the default mode.

## Notes
- 3D mouse input works only in the Windows desktop app. You can also pick the mode in [`SPACEMOUSE`](SPACEMOUSE-Command).
