`SPACEMOUSEPAN` sets the 3D mouse navigation mode to **Pan only**. Push or tilt the cap to pan. Twist and vertical pressure are ignored, so zoom and rotation stay fixed.

## Notes
- 3D mouse input works only in the Windows desktop app. You can also pick the mode in [`SPACEMOUSE`](SPACEMOUSE-Command).
