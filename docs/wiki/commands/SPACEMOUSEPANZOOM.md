`SPACEMOUSEPANZOOM` sets the 3D mouse navigation mode to **Pan and zoom**. Push or tilt the cap to pan; lift or press it to zoom. Twist is ignored and rotation stays fixed.

## Notes
- 3D mouse input works only in the Windows desktop app. You can also pick the mode in [`SPACEMOUSE`](SPACEMOUSE-Command).
