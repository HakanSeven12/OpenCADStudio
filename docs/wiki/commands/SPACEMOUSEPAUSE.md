---
summary: Pauses 3D mouse input, or resumes it when it is paused.
related: SPACEMOUSE, SPACEMOUSEAUTO, SPACEMOUSEPAN, SPACEMOUSEPANZOOM, SPACEMOUSE3D
web: Not available in the web app.
---

`SPACEMOUSEPAUSE` stops the 3D mouse from moving the view. Run it again to resume.

## Notes
- 3D mouse input works only in the Windows desktop app. You can also pick the mode in [`SPACEMOUSE`](SPACEMOUSE-Command).
