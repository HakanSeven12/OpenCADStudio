## Usage
1. Start the command. The Check Spelling window opens.
2. Choose where to check: **Entire drawing**, **Current space/layout** or **Selected objects**. For selected objects, click **Select objects**, pick them and press Enter.
3. Click **Start**. The check stops at the first word that is not in the dictionary and selects the object that holds it.
4. Pick a suggestion or type a replacement, then click a button to go on.
5. When no more words are found, the window shows "Spelling check complete."

## Options
| Option | What it does |
|---|---|
| **Change** | Replaces this occurrence of the word. |
| **Change All** | Replaces every occurrence of the word. |
| **Ignore** | Skips this occurrence. |
| **Ignore All** | Skips the word for the rest of the check. |
| **Add to Dictionary** | Adds the word to your own dictionary. |
| **Undo** | Undoes the last change. |
| **Main dictionary** | Chooses the language to check against. |
| **Settings** | Chooses whether dimension text and block attributes are checked, and which kinds of words are ignored: capitalized, mixed case, all uppercase, with numbers, with punctuation. It also lists the words you added; click one to remove it. |

## Notes
- Objects selected before you start the command are not used. The window opens on the scope you chose last.
- The check uses the spelling dictionaries installed on your computer. Only installed languages are listed.
- Your language, settings and added words are kept for the next time.
