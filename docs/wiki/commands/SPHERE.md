## Usage
1. Specify the center point, or type an option.
2. Specify the radius, or type `D` and specify the diameter. Press Enter to use the default shown.

## Options
| Option | What it does |
|---|---|
| **3P** (`3P`) | Specify three points on the sphere. |
| **2P** (`2P`) | Specify the two end points of a diameter. |
| **Ttr** (`T`) | Select two tangent objects, then enter the radius. The sphere touches both objects. |
| **Diameter** (`D`) | Enter the diameter instead of the radius. |

## Notes
- The last radius is kept as the default for the next sphere.
- The sphere is placed in the current UCS.
