## Usage
1. Type `STYLESMANAGER`, or pick **Plot Style Manager...** from the menu.
2. The editor opens with the plot style table chosen in the Plot dialog. Use **Load CTB/STB** to open another table.
3. Pick a color index (ACI) in the list. The list also shows how many layers use each index.
4. Set **Plot color** (**Choose color…**, **Reset**, or **Use object color**), **Lineweight** (or **Use object lineweight**) and **Screening (0-100)**.
5. Use **Save** or **Save As…** to write the table. **Clear Table** empties it.

## Notes
- The panel below the settings lists the layers in the current drawing that use the selected color index.
- If the table chosen in the Plot dialog cannot be loaded, an error is shown and the editor does not open.
