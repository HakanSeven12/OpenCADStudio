---
summary: Changes the width factor of selected single-line text so each text is exactly as wide as the width you enter.
related: TEXT, SCALETEXT, STYLE
---

## Usage
1. Select the text objects, then press Enter (skipped if you selected them before starting).
2. Enter the target width.

## Notes
- Only single-line text is changed; multiline text and other objects are ignored.
- The height and position of the text stay the same; only the width factor changes.
- Text on locked layers is skipped.
- The width must be a positive number.
- The change can be undone in one step.
