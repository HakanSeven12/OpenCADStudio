---
summary: Sends all text, multiline text and dimensions in the current space to the back of the draw order.
related: TEXTTOFRONT, DRAWORDER, HATCHTOBACK
---

## Usage
1. Type `TEXTTOBACK`. No selection is needed.

## Notes
- It acts on every single-line text, multiline text and dimension in the current space (model space, the current layout, or the block being edited).
- Those objects are left selected afterwards.
- If there are none, you see `TEXTTOBACK: no text or dimension objects.`
