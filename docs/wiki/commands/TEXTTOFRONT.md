---
summary: Brings all text, multiline text and dimensions in the current space to the front of the draw order.
related: TEXTTOBACK, DRAWORDER, HATCHTOBACK
---

## Usage
1. Type `TEXTTOFRONT`. No selection is needed.

## Notes
- It acts on every single-line text, multiline text and dimension in the current space (model space, the current layout, or the block being edited).
- Those objects are left selected afterwards.
- If there are none, you see `TEXTTOFRONT: no text or dimension objects.`
