## Usage
1. At `UCSICON [On / Off / NoOrigin / Origin]:`, type an option.

You can also type the option on the same line, for example `UCSICON OFF`.

## Options
| Option | What it does |
|---|---|
| **On** (`ON`) | Shows the UCS icon. |
| **Off** (`OFF`) | Hides the UCS icon. |
| **NoOrigin** (`NOORIGIN`) | Shows the icon in the corner of the view, not at the UCS origin. |
| **Origin** (`ORIGIN`) | Shows the icon at the UCS origin. |

## Notes
- The setting applies to model space and to every layout viewport of the drawing at once. The command line reports how many viewports were updated.
- You can undo the change.
