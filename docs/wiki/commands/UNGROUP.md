## Usage
1. At `Select grouped objects:`, select an object of each group you want to dissolve, then press Enter. You can also select them before you start.
2. The command line reports how many groups were dissolved.

## Notes
- Every group that contains a selected object is removed. The objects are not deleted or changed.
- If none of the selected objects belongs to a group, the command reports `No groups found for selected objects.`
- Objects on locked layers are left out.
- You can undo the change.
