## Usage
1. Run `VPJOIN`. It runs [`VPORTS`](VPORTS-Command) with the **Single** configuration.

## Notes
- In model space, the split model viewports become one viewport.
- In a paper layout, the layout's viewports are replaced by one viewport that fills the printable area. Unlock the viewport layers first; viewports on locked layers stop the command.
