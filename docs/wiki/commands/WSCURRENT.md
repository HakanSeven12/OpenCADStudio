## Usage
- Type `WSCURRENT` to see the current workspace: `WSCURRENT  current workspace: <name> [Classic/Ribbon]`.
- Type `WSCURRENT Classic` or `WSCURRENT Ribbon` as one line to switch. Start the line with `>` so that Space does not end the entry (`>WSCURRENT Classic`), or use it in a script.

## Options
| Option | What it does |
|---|---|
| **Classic** (`C`) | Hides the ribbon and shows the menu bar. If no toolbar is shown yet, the Draw, Modify, Layers and Properties toolbars appear. |
| **Ribbon** (`R`) | Shows the ribbon again. |

## Notes
- The choice is saved with your settings.
