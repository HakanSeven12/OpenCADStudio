---
summary: Opens the drawing file of a selected external reference in a new tab.
related: XREF, XATTACH, REFEDIT
---

## Usage
1. Select an external reference in the drawing.
2. Run `XOPEN`. The referenced drawing opens in its own tab.

## Notes
- Select the reference before you run the command; there is no selection prompt.
- If no external reference is selected you see `XOPEN: select an external reference (xref) to open.`
- If the saved path of the file no longer exists, an error is shown.
- The External Reference ribbon tab offers the same action for the selected reference.
