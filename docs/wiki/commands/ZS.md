---
summary: Zooms by a scale factor given on the same line, same as the Scale option of `ZOOM`.
related: ZOOM
---

`ZS <factor>` runs [`ZOOM`](ZOOM-Command) with the **Scale** option, for example `ZS 2`, `ZS 0.5X` or `ZS 1/50XP`. Give the factor on the same line (in a script, or start the line with `>` so that Space does not end the entry). Typed on its own, `ZS` is not recognized; use `ZOOM` and **Scale** instead.
