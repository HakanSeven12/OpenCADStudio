# Glossary

**Alias.** A short name typed instead of a command: `L` for `LINE`. See [Customization](Customization#command-aliases).

**Annotation scale.** The scale at which annotative objects are shown in model space or in a viewport. See [Annotation Scaling](Annotation-Scaling).

**Annotative.** An object (text, dimension, hatch, block…) whose size is given on paper and kept at every annotation scale.

**Associative.** Tied to other objects and updated when they change: an associative dimension follows the geometry it measures, an associative hatch its boundary, an associative array stays one editable object.

**Attribute.** A labelled value stored in a block reference, such as a door number. See [Blocks and Attributes](Blocks-and-Attributes).

**Block / block reference.** A named group of objects defined once, and each placement of it.

**ByBlock / ByLayer.** Property values that mean "take this from the block reference" and "take this from the layer".

**Command line.** The input line at the bottom of the window where commands are typed and prompts appear.

**Crossing window.** A selection rectangle drawn right to left: it selects objects inside it or crossing its edge.

**Current layer.** The layer new objects are placed on.

**DWG / DXF.** The drawing file formats Open CAD Studio reads and writes. DWG is binary and compact; DXF is a text exchange format.

**Dynamic block.** A block whose references change shape through grips: stretch, flip, show different states.

**Dynamic input.** Input fields next to the cursor that show the prompt and take typed values (**F12**).

**Extents.** The smallest box that holds every object in the drawing; `ZOOM` › Extents shows it.

**External reference (xref).** Another drawing shown inside yours without being copied into it.

**Freeze / thaw.** A frozen layer is hidden and skipped entirely; thawing shows it again.

**Grip.** A small square on a selected object that you drag to change it.

**Handle.** The permanent identifier of an object in the drawing.

**Hatch.** A pattern, solid colour or gradient filling a closed area.

**Isoplane.** One of the three planes (left, top, right) of isometric drafting.

**Layer.** A named set of objects sharing visibility, colour, linetype and other properties.

**Layout.** A sheet of paper (paper space) holding viewports, title blocks and notes, ready to print.

**Linetype.** The dash pattern of a line: continuous, dashed, centre, hidden…

**Lineweight.** The printed width of a line.

**Model space.** The space where you draw at full size.

**Object snap (osnap).** A pull towards an exact point on an object: endpoint, midpoint, centre and so on.

**Ortho.** A mode that keeps the cursor horizontal or vertical (**F8**).

**Paper space.** The space of a layout, measured in paper units.

**Plot style.** A rule that changes how objects print (colour, width, screening) without changing the drawing.

**Polar tracking.** Alignment paths at set angle steps from the last point (**F10**).

**Polyline.** A single object made of connected straight and curved segments.

**Purge.** Removing unused named items (layers, blocks, styles) from a drawing.

**Region.** A flat area object made from closed shapes.

**Solid (3D).** An exact 3D body with faces, edges and vertices.

**System variable.** A named setting of the drawing or the program, read and set at the command line. See [System Variables](System-Variables).

**Template (.dwt).** A drawing used as the starting point for new drawings.

**Transparent command.** A command run inside another one without ending it, typed with a leading apostrophe: `'ZOOM`.

**UCS / WCS.** The user coordinate system you place yourself, and the fixed world coordinate system.

**Underlay.** A PDF, DWF or DGN file shown under the drawing as a reference.

**Viewport.** A window onto the model: tiled viewports split the model view; layout viewports show the model on a sheet at a scale.

**Window selection.** A selection rectangle drawn left to right: it selects only objects entirely inside it.
