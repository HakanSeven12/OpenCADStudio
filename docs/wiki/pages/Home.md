# Open CAD Studio Help

Open CAD Studio is a free, open-source program for technical drawing, sheet layout and solid modelling. It opens and saves DWG and DXF drawings directly, runs on Windows, Linux and macOS, and also runs in a web browser with no installation.

This wiki explains how to use it, from the first line you draw to plotting a set of sheets. If you know your way around CAD already, start with [The User Interface](User-Interface) and the [Command Reference](Command-Reference); most command names and aliases will be familiar.
