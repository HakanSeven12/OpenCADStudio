# Keyboard Shortcuts

These are the default shortcuts. Change them under `CUI` › **Keyboard Shortcuts** or **Options › General › Keyboard Shortcuts…**. On macOS, **Cmd** takes the place of **Ctrl**.

## Function keys

| Key | Action |
|---|---|
| F1 | Help |
| F2 | Command history |
| F3 | Object snap on/off |
| F4 | 3D object snap on/off |
| F5 | Next isoplane |
| F6 | Dynamic UCS on/off |
| F7 | Grid on/off |
| F8 | Ortho on/off |
| F9 | Snap on/off |
| F10 | Polar tracking on/off |
| F11 | Object snap tracking on/off |
| F12 | Dynamic input on/off |
| Shift+F12 | Quad cursor menu on/off |

## Files and drawings

| Key | Action |
|---|---|
| Ctrl+N | New drawing from the default template |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+P | Plot |
| Ctrl+Q | Quit |
| Ctrl+Tab | Next drawing |
| Ctrl+Shift+Tab | Previous drawing |

## Editing

| Key | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z | Redo |
| Ctrl+C | Copy |
| Ctrl+Shift+C | Copy with base point |
| Ctrl+X | Cut |
| Ctrl+V | Paste |
| Ctrl+Shift+V | Paste as block |
| Ctrl+A | Select all |
| Delete | Erase the selection |
| Ctrl+F, Ctrl+H | Find and replace |
| Ctrl+K | Hyperlink |
| Ctrl+W | Selection cycling on/off |

## Window

| Key | Action |
|---|---|
| Ctrl+1 | Properties palette |
| Ctrl+9 | Command line on/off |
| Ctrl+0 | Clean screen |
| Ctrl+R | Next viewport |
| Alt | Ribbon key tips |

## At the command line

| Key | Action |
|---|---|
| Enter, Space | Confirm; at an empty prompt, repeat the last command |
| Esc | Cancel |
| Up, Down | Earlier and later input |
| Tab, Shift+Tab | Next and previous dynamic input field |

## Mouse

| Action | Result |
|---|---|
| Wheel | Zoom about the cursor |
| Middle button drag | Pan |
| Middle button double-click | Zoom extents |
| Shift + middle button drag | Orbit |
| Right-click | Context menu |
