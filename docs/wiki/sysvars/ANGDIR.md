---
summary: Sets whether positive angles run counterclockwise or clockwise.
type: Integer
saved: Drawing
default: 0 (Counterclockwise)
related: ANGBASE, AUNITS, AUPREC, UNITS
---

## Values
| Value | Meaning |
|---|---|
| 0 | Counterclockwise |
| 1 | Clockwise |

Any value other than 0 counts as clockwise.

## Notes
- Directions you type, and directions the program shows, follow this setting. Angle sizes do not change.
- The Clockwise box in the [`UNITS`](UNITS-Command) dialog sets this value.
