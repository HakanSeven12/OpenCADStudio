---
summary: Shows or hides annotative objects that do not support the current annotation scale.
type: On/Off (0/1)
saved: Drawing
default: 1 (On) in model space; 0 (Off) in a paper layout
related: CANNOSCALE, ANNOAUTOSCALE, ANNOSCALE
---

## Values
| Value | Meaning |
|---|---|
| 0 | Only annotative objects that support the current annotation scale are shown |
| 1 | All annotative objects are shown |

You can also type ON, OFF, TRUE or FALSE.

## Notes
- Model space and each paper layout keep their own value.
- The status bar has a button that switches this value.
