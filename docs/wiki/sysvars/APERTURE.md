---
summary: Sets how close, in screen pixels, the cursor must be to a point for object snap to catch it.
type: Integer
saved: Program settings
default: 25 (pixels)
related: PICKBOX, OSMODE
---

## Values
The accepted range is 4 to 40 pixels.

## Notes
- A larger value catches snap points from further away.
- Options › Selection › Aperture size sets the same value.
