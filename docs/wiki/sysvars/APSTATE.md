---
summary: Tells whether the Block Authoring Palettes are shown.
type: On/Off (0/1) read-only
saved: Not saved
default: 0 (Not shown)
related: BAUTHORPALETTE, BLOCKEDITOR, BEDIT
---

## Values
| Value | Meaning |
|---|---|
| 0 | The Block Authoring Palettes are not shown |
| 1 | The Block Authoring Palettes are shown |

## Notes
- [`BAUTHORPALETTE`](BAUTHORPALETTE-Command) opens and closes the palettes.
