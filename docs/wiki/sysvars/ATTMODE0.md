---
summary: Hides all block attributes; it sets ATTMODE to 0.
type: Command
saved: Drawing
default: Not applicable
related: ATTMODE, ATTDISP, ATTMODE1, ATTMODE2
---

## Notes
- This is the "Hide All Attributes" entry of the attribute display list on the Insert ribbon tab.
- It runs `ATTDISP OFF`. See [`ATTDISP`](ATTDISP-System-Variable).
