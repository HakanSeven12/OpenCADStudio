summary: Shows all block attributes, including invisible ones; it sets ATTMODE to 2.
type: Command
saved: Drawing
default: Not applicable
related: ATTMODE, ATTDISP, ATTMODE0, ATTMODE1
---

## Notes
- This is the "Display All Attributes" entry of the attribute display list on the Insert ribbon tab.
- It runs `ATTDISP ON`. See [`ATTDISP`](ATTDISP-System-Variable).
