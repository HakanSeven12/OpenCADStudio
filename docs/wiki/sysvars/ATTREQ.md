---
summary: Sets whether inserting a block asks for attribute values.
type: On/Off (0/1)
saved: Drawing
default: 1 (Ask)
related: ATTDIA, INSERT, ATTDEF
---

## Values
| Value | Meaning |
|---|---|
| 0 | No values are asked; every attribute takes its default value |
| 1 | Attribute values are asked |

## Notes
- [`ATTDIA`](ATTDIA-System-Variable) decides whether the values are asked in a dialog or on the command line.
