---
summary: Sets whether the Block Editor shows actions in action bars.
type: On/Off (0/1)
saved: Program settings
default: 1 (Action bars)
related: BEDIT, BESETTINGS
---

## Values
| Value | Meaning |
|---|---|
| 0 | No action bars are shown |
| 1 | Actions are shown in action bars next to their parameters |

## Notes
- The [`BESETTINGS`](BESETTINGS-Command) dialog sets this value too.
