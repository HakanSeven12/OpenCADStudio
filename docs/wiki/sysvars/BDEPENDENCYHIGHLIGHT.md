---
summary: Highlights the objects that depend on the selected parameter, grip or action in the Block Editor.
type: On/Off (0/1)
saved: Program settings
default: 1 (On)
related: BEDIT, BESETTINGS
---

## Values
| Value | Meaning |
|---|---|
| 0 | Dependent objects are not highlighted |
| 1 | Dependent objects are highlighted |

## Notes
- The [`BESETTINGS`](BESETTINGS-Command) dialog sets this value too.
