---
summary: Sets the size, in screen pixels, of parameter grips in the Block Editor.
type: Integer
saved: Program settings
default: 8 (pixels)
related: BGRIPOBJCOLOR, BPARAMETERSIZE, BESETTINGS
---

## Values
The accepted range is 1 to 255 pixels.

## Notes
- The [`BESETTINGS`](BESETTINGS-Command) dialog sets this value too.
