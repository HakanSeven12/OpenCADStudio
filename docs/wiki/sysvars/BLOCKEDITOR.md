---
summary: Tells whether the Block Editor is open in the current drawing.
type: On/Off (0/1) read-only
saved: Not saved
default: 0 (Closed)
related: BEDIT, BLOCKEDITLOCK, APSTATE, BLOCKTESTWINDOW
---

## Values
| Value | Meaning |
|---|---|
| 0 | The Block Editor is not open |
| 1 | The Block Editor is open |

## Notes
- [`BEDIT`](BEDIT-Command) opens the Block Editor.
