---
summary: Tells whether the current drawing window is a block test window.
type: On/Off (0/1) read-only
saved: Not saved
default: 0 (No)
related: BTESTBLOCK, BLOCKEDITOR
---

## Values
| Value | Meaning |
|---|---|
| 0 | The current window is not a test window |
| 1 | The current window is a test window |

## Notes
- [`BTESTBLOCK`](BTESTBLOCK-Command) opens a test window from the Block Editor.
