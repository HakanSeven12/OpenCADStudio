---
summary: Sets the font of parameter and action labels in the Block Editor.
type: String
saved: Program settings
default: Simplex.shx
related: BPARAMETERSIZE, BPTEXTHORIZONTAL, BESETTINGS
---

## Values
A font family, a font file, or a primary,bigfont pair. The value cannot be empty.

## Notes
- The [`BESETTINGS`](BESETTINGS-Command) dialog sets this value too.
