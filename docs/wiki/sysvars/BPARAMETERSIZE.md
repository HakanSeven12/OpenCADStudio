---
summary: Sets the size, in screen pixels, of parameter and action labels in the Block Editor.
type: Integer
saved: Program settings
default: 12 (pixels)
related: BPARAMETERFONT, BGRIPOBJSIZE, BESETTINGS
---

## Values
The accepted range is 1 to 255 pixels.

## Notes
- The [`BESETTINGS`](BESETTINGS-Command) dialog sets this value too.
