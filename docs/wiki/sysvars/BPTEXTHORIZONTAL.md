---
summary: Keeps parameter labels in the Block Editor horizontal instead of aligned with the parameter.
type: On/Off (0/1)
saved: Program settings
default: 1 (Horizontal)
related: BPARAMETERFONT, BPARAMETERSIZE, BESETTINGS
---

## Values
| Value | Meaning |
|---|---|
| 0 | Labels follow the direction of their parameter |
| 1 | Labels are always horizontal |

## Notes
- The [`BESETTINGS`](BESETTINGS-Command) dialog sets this value too.
