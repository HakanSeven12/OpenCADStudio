---
summary: Sets how the Block Editor shows objects that are hidden in the current visibility state.
type: On/Off (0/1)
saved: Not saved
default: 0 (Hide)
related: BVSTATE, BVHIDE, BVSHOW, BEDIT
---

## Values
| Value | Meaning |
|---|---|
| 0 | Hidden objects are not shown |
| 1 | Hidden objects are shown dimmed |

You can also type TOGGLE to switch the value.

## Notes
- It applies only while the Block Editor is open.
