---
summary: Sets whether new dimensional constraints are dynamic or annotational.
type: Integer
saved: Not saved
default: 0 (Dynamic)
related: DCFORM, DYNCONSTRAINTDISPLAY, CONSTRAINTNAMEFORMAT
---

## Values
| Value | Meaning |
|---|---|
| 0 | Dynamic constraints |
| 1 | Annotational constraints |

## Notes
- [`DCFORM`](DCFORM-Command) sets the same value.
- The value is kept for the current session only.
