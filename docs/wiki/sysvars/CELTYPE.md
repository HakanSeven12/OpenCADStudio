---
summary: Shows the linetype that new objects get.
type: String
saved: Drawing
default: ByLayer
related: LINETYPE, CELTSCALE, CECOLOR, CLAYER
---

## Notes
- [`SETVAR`](SETVAR-Command) can only read this variable. Use [`LINETYPE`](LINETYPE-Command) (Set current) to change it.
- ByLayer means new objects use the linetype of their layer.
