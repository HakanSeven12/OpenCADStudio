---
summary: Sets the linetype file that center line and center mark linetypes are read from.
type: String
saved: Drawing
default: the standard imperial linetype file in imperial drawings, the metric one in metric drawings
related: CENTERLTYPE, CENTERLINE, CENTERMARK
---

## Notes
- When you set a path to a linetype file that can be read, its linetypes are loaded into the drawing.
- In the web version, a file name other than the two defaults opens a file picker to choose the linetype file.
