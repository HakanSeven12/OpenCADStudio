---
summary: Sets the scale that new multilines are drawn with.
type: Real
saved: Drawing
default: 1.0
related: CMLJUST, CMLSTYLE, MLINE
---

## Values
Any finite number. The scale multiplies the element offsets of the multiline style.

## Notes
- [`MLINE`](MLINE-Command) reads this value and stores the scale you choose there.
