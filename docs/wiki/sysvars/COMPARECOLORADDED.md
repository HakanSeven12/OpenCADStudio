---
summary: Sets the color that the drawing comparison uses to show added objects.
type: Color (index, name or R,G,B)
saved: Program settings
default: 64,217,89 (green)
related: COMPARECOLORMODIFIED, COMPARECOLORREMOVED, COMPARETOLERANCE, COMPARE
---

## Values
A color index, a color name, or a red, green, blue triple such as `255,0,0`. 0 or BLACK gives black.

## Notes
- Used by [`COMPARE`](COMPARE-Command). The value is reported as R,G,B.
