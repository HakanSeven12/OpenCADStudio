---
summary: Sets the table style that new tables use.
type: String
saved: Drawing
default: Standard
related: TABLESTYLE, TABLE
---

## Notes
- The name must be a table style in the drawing. Case does not matter; the style name is kept as it is spelled in the drawing.
- Type `CTABLESTYLE` to be asked for a name, or use [`SETVAR`](SETVAR-Command). The table style control on the ribbon sets the same value.
