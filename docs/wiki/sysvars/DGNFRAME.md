---
summary: Controls whether the frame of attached DGN underlays is shown and plotted.
type: Integer
saved: Drawing
default: 0 (Hidden)
related: FRAME, PDFFRAME, DWFFRAME, DGNATTACH
---

## Values
| Value | Meaning |
|---|---|
| 0 | The frame is hidden and not plotted. |
| 1 | The frame is shown and plotted. |
| 2 | The frame is shown but not plotted. |

## Notes
- [`FRAME`](FRAME-System-Variable) sets this together with the other frame variables.
- The change can be undone.
