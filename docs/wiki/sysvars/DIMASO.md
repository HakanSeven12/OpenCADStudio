---
summary: Older switch for associative dimensions, kept for file compatibility.
type: On/Off (0/1)
saved: Drawing
default: 1 (On)
related: DIMASSOC
---

## Values
| Value | Meaning |
|---|---|
| 0 | Off |
| 1 | On |

## Notes
- Stored with the drawing; it does not change anything in Open CAD Studio yet. Use [`DIMASSOC`](DIMASSOC-System-Variable) to control dimension associativity.
