---
summary: Controls how objects are shown while you drag them.
type: Integer
saved: Drawing
default: 2 (Auto)
---

## Values
| Value | Meaning |
|---|---|
| 0 | Off. |
| 1 | On when requested. |
| 2 | Automatic. |

## Notes
- Stored with the drawing; it does not change anything in Open CAD Studio yet. Objects always show a preview while you drag them.
