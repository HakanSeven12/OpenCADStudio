---
summary: Shows whether the External References palette is open.
type: On/Off (0/1) read-only
saved: Not saved
default: 0 (Closed)
related: EXTERNALREFERENCES
---

## Values
| Value | Meaning |
|---|---|
| 0 | The External References palette is closed. |
| 1 | The External References palette is open. |

## Notes
- You cannot set this variable. Use [`EXTERNALREFERENCES`](EXTERNALREFERENCES-Command) to open the palette.
