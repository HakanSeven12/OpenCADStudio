---
summary: Shows or hides the file tabs at the top of the drawing area.
type: Toggle (takes no value)
saved: Program settings
default: File tabs shown
related: LAYOUTTAB
---

## Values
`FILETAB` takes no value. Each time you enter it, the file tabs switch between shown and hidden.

## Notes
- The File Tabs button on the View tab of the ribbon does the same.
- The choice is kept for the next session.
