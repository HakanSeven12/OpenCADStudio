---
summary: Hides the frames of images, underlays, wipeouts, clipped references and point cloud clips.
type: Action (takes no value)
saved: Drawing
default: None (it is an action)
related: FRAME, FRAMES1, FRAMES2, FRAMES3
---

## Values
`FRAMES0` takes no value. Entering it sets [`FRAME`](FRAME-System-Variable) to 0, so all frames are hidden and not plotted.

## Notes
- It is the "Hide frames" item of the Frames list on the Insert tab of the ribbon.
- The result is stored in the drawing through the frame variables.
