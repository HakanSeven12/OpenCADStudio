---
summary: Shows the frames of images, underlays, wipeouts, clipped references and point cloud clips without plotting them.
type: Action (takes no value)
saved: Drawing
default: None (it is an action)
related: FRAME, FRAMES0, FRAMES1, FRAMES3
---

## Values
`FRAMES2` takes no value. Entering it sets [`FRAME`](FRAME-System-Variable) to 2, so all frames are shown but not plotted.

## Notes
- It is the "Display but don't plot frames" item of the Frames list on the Insert tab of the ribbon.
- The result is stored in the drawing through the frame variables.
