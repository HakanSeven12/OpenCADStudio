---
summary: Sets whether a pick of an error in the Geometry Cleanup palette zooms to it.
type: On/Off (0/1)
saved: Program settings
default: 1 (On)
related: GEOMETRYCLEANUPOPEN, GEOMETRYERRORREVIEWCLOSE
---

## Values
| Value | Meaning |
|---|---|
| 0 | A pick zooms to the error only when the error is not all in view |
| 1 | A pick zooms to the error |

## Notes
- The Auto Zoom button on the review toolbar sets it too.
