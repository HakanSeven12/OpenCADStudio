---
summary: Turns the grid on or off in the current viewport.
type: On/Off (0/1)
saved: Drawing
default: 0 (Off)
related: GRIDUNIT, GRID
---

## Values
| Value | Meaning |
|---|---|
| 0 | The grid is hidden. |
| 1 | The grid is shown. |

## Notes
- Each viewport keeps its own grid setting.
- The grid button on the status bar and the [`GRID`](GRID-Command) command switch the same setting.
