---
summary: Sets the color of grips that are not selected.
type: Integer
saved: Program settings
default: 0 (Theme color)
related: GRIPHOT, GRIPHOVER, GRIPSIZE, GRIPDYNCOLOR
---

## Values
| Value | Meaning |
|---|---|
| 0 | The grip color of the current color theme. |
| 1 to 255 | A color index. |

## Notes
- You can also set it in the Options dialog.
