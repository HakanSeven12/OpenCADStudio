---
summary: Sets the color of a selected (hot) grip.
type: Integer
saved: Program settings
default: 0 (Theme color)
related: GRIPCOLOR, GRIPHOVER, GRIPSIZE
---

## Values
| Value | Meaning |
|---|---|
| 0 | The hot grip color of the current color theme. |
| 1 to 255 | A color index. |

## Notes
- You can also set it in the Options dialog.
