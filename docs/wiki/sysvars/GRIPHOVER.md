---
summary: Sets the color of a grip while the cursor is over it.
type: Integer
saved: Program settings
default: 0 (Theme color)
related: GRIPCOLOR, GRIPHOT, GRIPSIZE
---

## Values
| Value | Meaning |
|---|---|
| 0 | The hover grip color of the current color theme. |
| 1 to 255 | A color index. |

## Notes
- You can also set it in the Options dialog.
