---
summary: Sets the largest number of selected objects that still show grips.
type: Integer
saved: Program settings
default: 100
related: GRIPSIZE, GRIPCOLOR
---

## Values
A whole number from 0 to 32767. 0 means no limit.

## Notes
- When more objects than this are selected, no grips are shown.
- The Options dialog has a slider for this value up to 1000. Larger values can be set with SETVAR.
