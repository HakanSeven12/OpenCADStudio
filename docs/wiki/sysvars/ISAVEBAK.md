---
summary: Controls whether a backup copy (.bak) of a file is made when you save over it.
type: On/Off (0/1)
saved: Program settings
default: 1 (On)
related: SAVE, SAVEFILEPATH
---

## Values
| Value | Meaning |
|---|---|
| 0 | No backup copy is made. |
| 1 | Before a file is overwritten, the old file is copied to a `.bak` file next to it. |

## Notes
- Automatic saves never make a backup copy.
- The same switch is in the Options dialog.
