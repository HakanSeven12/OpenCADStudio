---
summary: Controls whether a layout gets a viewport the first time it is opened.
type: On/Off (0/1)
saved: Program settings
default: 1 (On)
related: LAYOUT, TILEMODE, CTAB
---

## Values
| Value | Meaning |
|---|---|
| 0 | A layout opens with no viewport. |
| 1 | A layout that has no viewport gets one when it is opened for the first time. |

## Notes
- Takes `1` / `0` or `ON` / `OFF`. The command line shows the value as `ON` or `OFF`.
- A layout that already has viewports is not changed.
