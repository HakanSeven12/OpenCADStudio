---
summary: Shows or hides the Model and layout tabs.
type: On/Off (0/1)
saved: Program settings
default: 1 (tabs shown)
related: FILETAB, LAYOUT, CTAB
---

## Values
| Value | Meaning |
|---|---|
| 0 | The Model and layout tabs are hidden. |
| 1 | The Model and layout tabs are shown. |

## Notes
- Typing `LAYOUTTAB` switches the tabs on or off.
- The ribbon's View tab has the same switch.
