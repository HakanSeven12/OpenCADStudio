---
summary: Sets the number of decimal places shown for lengths and coordinates.
type: Integer
saved: Drawing
default: 4
related: LUNITS, AUPREC, UNITS
---

## Values
A whole number from 0 to 8. A larger value is stored as 8 and a negative one as 0.

## Notes
- [`UNITS`](UNITS-Command) sets it from a dialog.
- It applies to the scientific, decimal and engineering formats of [`LUNITS`](LUNITS-System-Variable).
