---
summary: Shows or hides the menu bar.
type: On/Off (0/1)
saved: Program settings
default: 0 (hidden)
related: RIBBON
---

## Values
| Value | Meaning |
|---|---|
| 0 | The menu bar is hidden. |
| 1 | The menu bar is shown. |

## Notes
- The Options dialog and the Quick Access Toolbar menu have the same switch.
