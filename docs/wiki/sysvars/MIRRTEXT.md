---
summary: Controls whether MIRROR reverses text or keeps it readable.
type: On/Off (0/1)
saved: Drawing
default: 0 (Off)
related: MIRROR
---

## Values
| Value | Meaning |
|---|---|
| 0 | Mirrored text keeps reading left to right; only its position is mirrored. |
| 1 | Text is mirrored like any other object and reads backwards. |

## Notes
- Used by [`MIRROR`](MIRROR-Command).
- Changing it can be undone.
