---
summary: Stores the scale value for OLE objects in model space that is kept in the drawing file.
type: Real
saved: Drawing
default: 1.0
related: INSERTOBJ, OLEFRAME, OLEHIDE
---

## Values
Any number of 0 or more. A negative value is refused.

## Notes
- Stored with the drawing; it does not change anything in Open CAD Studio yet.
