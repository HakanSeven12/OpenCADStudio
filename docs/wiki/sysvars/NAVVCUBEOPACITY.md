---
summary: Sets how opaque the ViewCube is while the cursor is away from it.
type: Integer
saved: Program settings
default: 50 (percent)
related: NAVVCUBE
---

## Values
An integer from 0 to 100, in percent. The cube turns fully opaque when the cursor reaches its corner of the viewport. 100 keeps it opaque all the time; 0 hides it until the cursor gets there.

## Notes
- Type `NAVVCUBEOPACITY` to be asked for a value, or use [`SETVAR`](SETVAR-Command).
