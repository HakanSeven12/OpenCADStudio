---
summary: Sets whether object transparency is used when you plot.
type: Integer
saved: Program settings
default: 1 (Use the plot setting)
related: PLOT
---

## Values
| Value | Meaning |
|---|---|
| 0 | Transparency is never plotted. |
| 1 | Transparency is plotted when the Plot transparency option in the [`PLOT`](PLOT-Command) dialog is on. |
| 2 | Transparency is always plotted. |
