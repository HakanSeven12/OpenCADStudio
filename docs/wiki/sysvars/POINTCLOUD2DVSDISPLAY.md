---
summary: Sets whether point clouds show a box and a message in the 2D Wireframe visual style.
type: On/Off (0/1)
saved: Drawing
default: 0
related: POINTCLOUDATTACH
---

## Values
| Value | Meaning |
|---|---|
| 0 | In 2D Wireframe, each cloud shows its extents box with a message across the base. |
| 1 | In 2D Wireframe, the box and message are not shown. |

## Notes
- The 2D Wireframe visual style never draws the points of a cloud. Use another visual style to see them.
