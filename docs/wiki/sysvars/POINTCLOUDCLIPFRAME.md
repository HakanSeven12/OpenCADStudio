---
summary: Sets whether the crop boundary of point clouds is shown and plotted.
type: Integer
saved: Drawing
default: 2 (Shown, not plotted)
related: FRAME, POINTCLOUDCROP, POINTCLOUDUNCROP
---

## Values
| Value | Meaning |
|---|---|
| 0 | The crop boundary is hidden. |
| 1 | The crop boundary is shown and plotted. |
| 2 | The crop boundary is shown but not plotted. |

## Notes
- [`FRAME`](FRAME-System-Variable) sets this value together with the other frame variables.
