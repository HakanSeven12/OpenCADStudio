---
summary: Sets whether new point clouds are attached locked.
type: On/Off (0/1)
saved: Drawing
default: 0 (Unlocked)
related: POINTCLOUDATTACH
---

## Values
| Value | Meaning |
|---|---|
| 0 | New point clouds are attached unlocked. |
| 1 | New point clouds are attached locked. |

## Notes
- It is used by [`POINTCLOUDATTACH`](POINTCLOUDATTACH-Command) when the attach options do not set the lock.
