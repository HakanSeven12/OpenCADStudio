---
summary: Sets the largest number of points that a point cloud shows.
type: Integer
saved: Drawing
default: 10000000
related: POINTCLOUDDENSITY, POINTCLOUDLOD
---

## Values
Accepted values are whole numbers from 1000000 to 25000000. A value outside the range ends the command.

## Notes
- [`POINTCLOUDDENSITY`](POINTCLOUDDENSITY-System-Variable) and [`POINTCLOUDLOD`](POINTCLOUDLOD-System-Variable) reduce this number further.
