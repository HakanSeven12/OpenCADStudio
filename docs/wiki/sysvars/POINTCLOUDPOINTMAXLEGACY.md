---
summary: Point cloud setting for the point limit of older point cloud formats.
type: Integer
saved: Drawing
default: 1500000
related: POINTCLOUDPOINTMAX
---

## Values
Accepted values are whole numbers from 1500000 to 10000000. A value outside the range ends the command.

## Notes
- Stored with the drawing; it does not change anything in Open CAD Studio yet.
