---
summary: Turns the Quick Properties panel on or off for selected objects.
type: Integer
saved: Program settings
default: 0 (Off)
related: QPLOCATION, QUICKPROPERTIES, PROPERTIES
---

## Values
| Value | Meaning |
|---|---|
| 0 | The Quick Properties panel is off. |
| 1 | The Quick Properties panel opens when you select objects. |
| 2 | Same as 1. The panel shows for every object type. |

## Notes
- The Quick Properties button on the status bar and the [`QUICKPROPERTIES`](QUICKPROPERTIES-Command) command switch it too.
