type: On/Off (0/1)
saved: Drawing
default: 0 (Off)
---

## Values
| Value | Meaning |
|---|---|
| 0 | Off. |
| 1 | On. |

## Notes
- Stored with the drawing; it does not change anything in Open CAD Studio yet. Text is always drawn in full.
