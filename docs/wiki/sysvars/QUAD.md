---
summary: Turns the Quad cursor menu on or off.
type: On/Off (0/1)
saved: Program settings
default: 0 (Off)
related: QUADWIDTH, QUADCOMMANDLAUNCH, SHORTCUTMENU
---

## Values
| Value | Meaning |
|---|---|
| 0 | The Quad cursor menu is off. Right-click works as before. |
| 1 | The Quad cursor menu is on. It offers commands for the object under the cursor or the selection. |

## Notes
- Shift+F12 and the QUAD button on the status bar switch it.
- More Quad options are in [`OPTIONS`](OPTIONS-Command), in the Quad Cursor Menu section.
