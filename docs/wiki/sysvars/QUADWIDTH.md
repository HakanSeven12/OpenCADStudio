---
summary: Sets the number of columns in the expanded Quad cursor menu.
type: Integer
saved: Program settings
default: 6
related: QUAD, QUADCOMMANDLAUNCH
---

## Values
Accepted values are whole numbers from 2 to 12. A larger whole number is set to 12, and 0 or 1 is set to 2.

## Notes
- Set it in [`OPTIONS`](OPTIONS-Command), in the Quad Cursor Menu section.
