---
summary: Sets the approximate arc length of new revision clouds.
type: Real
saved: Drawing
default: 0 (Based on the view)
related: REVCLOUD, REVCLOUDARCVARIANCE
---

## Values
Enter a length in drawing units, or pick two points to use the distance between them. When the value is 0, [`REVCLOUD`](REVCLOUD-Command) uses one twentieth of the current view's diagonal.

## Notes
- The Arc length option of [`REVCLOUD`](REVCLOUD-Command) also sets this value.
