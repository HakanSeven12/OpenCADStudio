---
summary: Sets how strong the fill of selection windows is.
type: Integer
saved: Program settings
default: 12 (percent)
related: SELECTIONAREA, WINDOWAREACOLOR, CROSSINGAREACOLOR
---

## Values
A whole number from 0 to 100 (percent). Higher values make the fill more solid.

## Notes
- The fill is drawn only while [`SELECTIONAREA`](SELECTIONAREA-System-Variable) is on.
