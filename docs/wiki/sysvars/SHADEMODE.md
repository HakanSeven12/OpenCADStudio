---
summary: Sets the visual style of the current view.
type: Keyword
saved: Not saved
default: —
related: VISUALSTYLES
---

## Values
| Value | Meaning |
|---|---|
| 2 | Wireframe 2D |
| 3 or W | Wireframe 3D |
| H | Hidden Line |
| S, R or C | Gouraud Shaded |
| E | Gouraud Shaded + Edges |

Flat Shaded and Flat Shaded + Edges can be picked by name from the prompt.

## Notes
- Typing `SHADEMODE` shows a visual style prompt. It works the same way as the visual style prompt of [`VISUALSTYLES`](VISUALSTYLES-Command).
- There is no stored number; the chosen style is reported on the command line.
