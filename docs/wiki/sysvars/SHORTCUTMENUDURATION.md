---
summary: Sets how long the right mouse button must be held to open the shortcut menu with time-sensitive right-click.
type: Integer
saved: Program settings
default: 250 (milliseconds)
related: SHORTCUTMENU
---

## Values
A whole number of milliseconds from 100 to 1000.

## Notes
- Used only when [`SHORTCUTMENU`](SHORTCUTMENU-System-Variable) is set to time-sensitive right-click. A shorter press counts as Enter.
