---
summary: Controls whether the original shapes stored in the history of 3D solids are shown.
type: Integer
saved: Drawing
default: 1 (per solid)
related: SOLIDHIST
---

## Values
| Value | Meaning |
|---|---|
| 0 | History is hidden on every solid. |
| 1 | Each solid follows its own Show History property. |
| 2 | History is shown on every solid that has one. |

## Notes
- The Show History property in the Properties panel can only be changed while this is 1.
- Changing the value can be undone. It is also in Options › 3D Modeling.
