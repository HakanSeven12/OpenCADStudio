---
summary: Sets the kind of object SKETCH creates.
type: Integer
saved: Drawing
default: 0 (lines)
related: SKETCH, SKETCHINC, SKTOLERANCE
---

## Values
| Value | Meaning |
|---|---|
| 0 | Separate lines |
| 1 | A polyline |
| 2 | A spline |

## Notes
- Choosing the Type option inside [`SKETCH`](SKETCH-Command) also updates this variable.
