---
summary: Controls whether the control frame of spline-fit 3D polylines is drawn.
type: On/Off (0/1)
saved: Drawing
default: 0 (Off)
related: PEDIT, SPLINESEGS
---

## Values
| Value | Meaning |
|---|---|
| 0 | Only the smooth curve is drawn. |
| 1 | The frame through the control vertices is drawn as well. |

## Notes
- Only 0 or 1 is accepted; any other value is refused and you are asked again.
- The control vertices stay snap points either way.
