---
summary: Sets how often, in seconds, the status of sheets in the Sheet Set Manager is checked again.
type: Integer
saved: Program settings
default: 60 (seconds)
related: SSMSHEETSTATUS, SHEETSET
---

## Values
A whole number of seconds from 20 to 600.

## Notes
- Used only when [`SSMSHEETSTATUS`](SSMSHEETSTATUS-System-Variable) is 2.
