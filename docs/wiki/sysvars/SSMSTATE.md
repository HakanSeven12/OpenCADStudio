---
summary: Shows whether the Sheet Set Manager is open.
type: On/Off (0/1), read-only
saved: Not saved
default: 0 (closed)
related: SHEETSET, SHEETSETHIDE, SSMAUTOOPEN
---

## Values
| Value | Meaning |
|---|---|
| 0 | The Sheet Set Manager is closed. |
| 1 | The Sheet Set Manager is open. |

## Notes
- It cannot be set. Open the manager with [`SHEETSET`](SHEETSET-Command) and close it with [`SHEETSETHIDE`](SHEETSETHIDE-Command).
