---
summary: Shows the name of the current text style.
type: String read-only
saved: Drawing
default: Standard
related: STYLE
---

## Notes
- [`SETVAR`](SETVAR-Command) only reports the name. To change the current style, use the [`STYLE`](STYLE-Command) command.
- Typing `TEXTSTYLE` on the command line runs the [`STYLE`](STYLE-Command) command.
- Fields can show the value.
