---
summary: Switches between model space and the paper layouts.
type: On/Off (0/1)
saved: Drawing
default: 1 (Model)
related: CTAB, LAYOUT
---

## Values
| Value | Meaning |
|---|---|
| 0 | A paper layout is current |
| 1 | The Model tab is current |

## Notes
- The value follows the current layout tab. Clicking a layout tab changes it.
- Setting 0 opens the paper layout that was last current, else the first one. A drawing without a paper layout refuses 0.
