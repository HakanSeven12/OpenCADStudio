---
summary: Sets whether TRIM and EXTEND start in Quick or Standard mode.
type: On/Off (0/1)
saved: Program settings
default: 1 (Quick)
related: TRIM, EXTEND
---

## Values
| Value | Meaning |
|---|---|
| 0 | Standard: you first select the cutting or boundary edges |
| 1 | Quick: every object is a cutting or boundary edge, and you can pick at once |

## Notes
- Affects [`TRIM`](TRIM-Command) and [`EXTEND`](EXTEND-Command).
