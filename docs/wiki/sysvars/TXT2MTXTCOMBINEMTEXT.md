---
summary: Sets whether TXT2MTXT combines the selected text into one multiline text object.
type: On/Off (0/1)
saved: Program settings
default: 1 (Combine)
related: TXT2MTXT, TXT2MTXTTEXTORDER, TXT2MTXTWORDWRAP, TXT2MTXTLINESPACING
---

## Values
| Value | Meaning |
|---|---|
| 0 | Each text object becomes its own multiline text object |
| 1 | All selected text becomes one multiline text object |

## Notes
- The Settings window of [`TXT2MTXT`](TXT2MTXT-Command) (the SEttings option) sets it too.
- The other TXT2MTXT variables only matter while this is 1.
