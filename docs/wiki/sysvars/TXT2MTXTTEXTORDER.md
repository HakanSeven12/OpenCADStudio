---
summary: Sets the order in which TXT2MTXT joins the selected text.
type: On/Off (0/1)
saved: Program settings
default: 0 (Top down)
related: TXT2MTXT, TXT2MTXTCOMBINEMTEXT
---

## Values
| Value | Meaning |
|---|---|
| 0 | Top to bottom; text at the same height keeps the selection order |
| 1 | The order in which you selected the objects |

## Notes
- Only used while [`TXT2MTXTCOMBINEMTEXT`](TXT2MTXTCOMBINEMTEXT-System-Variable) is 1.
- The Settings window of [`TXT2MTXT`](TXT2MTXT-Command) sets it too.
