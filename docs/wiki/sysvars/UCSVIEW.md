---
summary: Sets whether a saved named view keeps the current UCS.
type: On/Off (0/1)
saved: Program settings
default: 1 (On)
related: VIEW, UCS
---

## Values
| Value | Meaning |
|---|---|
| 0 | Views are saved without a UCS |
| 1 | The current UCS is saved with the view |

## Notes
- The settings of the [`VIEW`](VIEW-Command) command on the command line can change it too.
