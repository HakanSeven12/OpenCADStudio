---
summary: Sets the edge color of the shaded-with-edges visual styles.
type: Color
saved: Program settings
default: BLACK
related: VSCURRENT, VSEDGESMOOTH
---

It accepts a color index, a color name, or R,G,B values. BLACK or 0 goes back to black edges.

## Notes
- Used by Flat Shaded + Edges and Gouraud Shaded + Edges. See [`VSCURRENT`](VSCURRENT-System-Variable).
