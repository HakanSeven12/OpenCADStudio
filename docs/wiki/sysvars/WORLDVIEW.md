---
summary: Sets whether 3D view input is taken relative to the world coordinate system or the current UCS.
type: On/Off (0/1)
saved: Drawing
default: 1 (World)
related: UCS
---

## Values
| Value | Meaning |
|---|---|
| 0 | Current UCS |
| 1 | World coordinate system |

## Notes
- Stored with the drawing; it does not change anything in Open CAD Studio yet.
