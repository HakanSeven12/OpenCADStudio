---
summary: Sets how much external references fade toward the background, in percent.
type: Integer
saved: Program settings
default: 50
related: XFADECTL, XREF, XATTACH
---

The accepted range is -90 to 90. Positive values fade the references. 0 or a negative value shows them without fading.

## Notes
- The Reference panel of the Insert ribbon tab has a fade switch and amount. The switch flips the value between positive and negative, so the amount is kept.
