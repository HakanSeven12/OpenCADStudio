---
summary: Sets how much objects outside the reference being edited fade, in percent.
type: Integer
saved: Program settings
default: 70
related: REFEDIT, XDWGFADECTL
---

The accepted range is 0 to 90. Higher values fade the other objects more.

## Notes
- Used while you edit a block or reference in place with [`REFEDIT`](REFEDIT-Command).
