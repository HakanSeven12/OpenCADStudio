---
summary: Sets the direction in which the mouse wheel zooms.
type: On/Off (0/1)
saved: Program settings
default: 0 (Normal)
related: ZOOMFACTOR, ZOOM
---

## Values
| Value | Meaning |
|---|---|
| 0 | Normal: rolling the wheel forward zooms in |
| 1 | Reversed: rolling the wheel forward zooms out |

## Notes
- The "Reverse mouse wheel zoom" box in the [`OPTIONS`](OPTIONS-Command) window sets it too.
